# CCD 文本风格

本轮对照已安装的 Create 6.0.10-280 JAR 中 `assets/create/lang/zh_cn.json` 与 `en_us.json`，重点阅读物品舱口工具提示、流体容器护目镜信息、动力泵和储罐思索文本。风格参考不替代 CCD 实际行为核对。

- 护目镜沿用 Create 的“流体容器信息：”“容量：”及原生排版。设备状态用短标签，数值与单位由现有格式化代码处理。
- 工具提示先解释用途，再按条件解释结果；右击、潜行、扳手操作单独说明。下划线只强调关键对象和动作，保留容量、限制和过滤规则。
- 思索标题说明主题；每条字幕围绕当前画面中的一个动作展开。英文字面回退与中英文翻译同步，避免生成文本与运行时文本不一致。
- 保留注册名称、翻译键、占位符和当前玩法。增压泵旧提示中的“旋转方向决定流向”已纠正：其继承原生动力泵的方向控制，使用扳手反转。
- 历史 `rewrite-tooltips.py` 和旧生成器包含早期规则，不应直接作为当前语言文件的来源。本轮编辑脚本为 `refine-create-text.py`，运行后使用 `check-tooltips.py` 校验。

本次修改主要覆盖设备工具提示、护目镜状态与全部十个思索主题；配置说明、配方和操作逻辑不变。客户端完整字幕播放仍需另行检查。
