# 便携泵六方向支持

取消便携泵的水平放置／水平扳手限制，沿用 PumpOrientation 和 Create 扳手的整机点击轴旋转。支持六个管口方向及四档 ROLL；上下管口对接也参与 PumpPlacement。

静态机身新增24姿态映射；动态风箱和压板在 PumpRenderFrame 局部坐标下压缩／移动。两端半轴仍根据实际世界传动轴绘制。选择和交互形状将动态 strokeShape 的各方盒绕方块中心转换到世界姿态，风箱压缩方向与模型一致。按后续确认的方案，实体碰撞固定使用展开轮廓（stroke=0）并随姿态旋转，防止承托面收缩使踩踏实体陷入；压缩时可能有少量视觉悬空。手动正反转、持续时间、流量、范围与容量未调整。

116 项基础 GameTest通过，含24姿态形状压缩方向、两轴孔不与管口重叠、上下管口对接及原手动供能／停转。客户端动态视觉与完整第三方运动结构尚未实机验收。JAR未更新。
