# 端点泵改用原生管网输送

缓存泵、万向泵、输送式创造储罐已删除每刻 BFS 和末端扫描。每刻仅进行固定数量的相邻容器交互；跨管道传输交由 Create FluidNetwork。

NativeEndpointPump 是仅用于调用原生 distributePressureTo 的压力适配器，不放入世界、不注册透明管道行为。压力在初始化、转速变化、接口／朝向变化或管网结构通知时刷新；原生压力传播本身仍会扫描管网，正常稳定运行不由 CCD 每刻重复遍历。

- 缓存泵：保留有限储液，只有有动力的出液口可被管网抽取，其他面只接收填充，不主动抽液。
- 万向泵：各输入／输出面向原生管网提供不同方向的压力；内部共用缓存和输入／输出预算，停止后不主动输送。
- 创造储罐：选定流体作为无限源，无需旋转动力；输出压力由适配器提供。容器模式在原生目标填充处拒绝开放管口，世界模式允许原生 OpenEndedPipe 排液；相邻开放口继续使用持久化 OpenEndedPipe。
- 流量计：跨管道输送统一经过原生 FluidNetwork 计量入口，不再由三种元件单独记录整条路径。

本轮不代表 Pipes’n’Physics 兼容已经完成；其接管原生压力／传输后的泵识别、创建设备角色与流量读数仍需独立适配。相邻端点转移有模拟、执行和余量退回，但任意第三方违规能力的守恒仍取决于它正确实现 IFluidHandler。

验证：82 项基础 GameTest 全部通过，包括缓存／创造源跨管道供液、万向泵跨管道取送与停转、直接世界输出模式以及原有功能。万向泵测试改为等待原生流动建立，而不是要求直接跳过管道立即到达。尚未客户端和 PnP 联调，JAR 未更新。
