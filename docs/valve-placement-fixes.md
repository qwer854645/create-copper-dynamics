# 阀门物品贴图与管口放置修正

- 红石双向泵、红石三通的物品生成脚本统一建立贴图变量，元素面仅使用 `#变量`，避免原版模型烘焙时出现缺失贴图。
- 三通仪表根据支路在局部 X 轴的方向选择原始或镜像 UV 底图。镜像模型由原始模型生成，保留用户提供的倒置 cuboid 边界、玻璃和贴图；指针仍使用原来的动态旋转。
- 流体发射器的后接口、创造输液罐的出液口、三通的公共口优先对齐被点击的流体接口，然后按视线顺序寻找邻居。三通额外选择能连接邻管的支路方向。
- 流体访问口与桥优先识别被点击容器的对应面流体能力，避免仅暴露特定面能力的容器漏判。
- 共用管口检测识别三通的全部物理管口，不受当前通断状态影响；泵的轴面与机壳面不视为流体口。

验证：贴图引用检查、物品重新生成一致性检查、198 个模型／513 条方块状态配置审计通过；离线预览在 `outputs/valve-fixes/preview.png`。
本轮未运行 Gradle 编译、GameTest 或客户端，JAR 未更新。
