# 流体过滤器

新增 ccd:fluid_filter 与 ccd:fluid_attribute_filter，均继承 Create FilterItem，以自定义 FilterItemStack 接入原生流体过滤设备；未替换 Create 自带两种过滤器。材质与显示变换直接引用原版 filter、attribute_filter，不改写已有美术资源。

主手右键打开设置。普通流体过滤器有 18 个样本位置，允许／拒绝列表、仅流体种类／匹配流体组件两组设置。空允许列表拒绝全部，空拒绝列表接受全部。

属性过滤器从样本提取来源模组、流体标签、温度类别（1000 K 为热类别阈值）、密度类别（负密度／其他）、是否发光。选择样本后点击属性按钮循环候选，再点击目标位置加入规则；满足任意／全部，Shift+左键可对单项取反，右键删除。当前最多 18 条规则。

玩家物品栏点击桶或容器后点击目标位置，或从物品栏拖到目标位置。通过 FluidStockItem.sample 读取流体能力，不排空容器。JEI 注册原生 ghost ingredient handler，支持直接拖入 FluidStack 或含流体物品；EMI 注册 drag/drop handler，支持流体和容器。EMI 直接流体样本当前只保留流体种类，JEI 保留完整 FluidStack 组件。均不生成真实流体物品、不消耗流体。

独立设置菜单锁定主手物品和快捷栏位置，服务端验证菜单 ID、当前物品及规则索引，规则保存在可同步的数据组件中。配方为相应 Create 过滤器 + 流体管道。中英文名称、创造栏与资源已注册。

编译通过；两项新增 GameTest 通过，覆盖原生 wrapper 识别、序列化、白黑名单、属性组合与取反、桶样本不消耗。完整 52 项测试中 51 项通过，既有智能集液栅轮廓简化检查失败。JEI/EMI 拖拽及界面操作尚未实际客户端验证；未更新发布 JAR。
