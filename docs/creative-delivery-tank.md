# 输送式创造流体储罐

新增 ccd:creative_delivery_fluid_tank，无生存配方。创造玩家持含流体容器右键设定无限流体，不消耗样本；潜行空手清空。六向开口、扳手原生旋转。无限流体 capability 仅对开口暴露，允许抽取、不接受填充。设定流体保存及客户端同步。

主体和开口源自 Create 移动式流体接口，主体材质使用创造流体储罐。方块与物品共享单一模型，无伸缩 partial。原版接口及创造储罐材质归属上游。

自动输送采用有界 BFS，最大距离 256 格，最多访问 4096 个位置，每 tick 总输出上限 1000000 mB，不加载区块。检查相邻管道互通接口与过滤允许，经过阀门时遵守开放面，在其他动力泵处停止。直接填充连通端点，没有原生管内流动动画；属于快速供液源，不是新增旋转动力泵。多个端点按遍历顺序分配，未实现公平轮询。

资源引用检查通过，未构建、启动客户端或实际输送测试，JAR 未更新。

世界排液更新：使用 Create OpenEndedPipe 处理开放端，原生的积液、放置流体和特殊流体效果保持一致，开放端未排完的流体持久保存。新增原生 ScrollValueBehaviour 模式槽，默认仅向容器输送，空手使用槽位切换为允许世界输出；扳手右键仍旋转开口，潜行扳手仍回收，不要求扳手设置模式。该开关限制本设备的自动世界输出，不限制独立外部泵从无限源抽液后自行排液。

服务端测试通过：默认模式不向空气排液、允许世界输出时原生放水、开放端部分桶保存后继续凑桶。全套唯一失败仍为既有智能集液栅轮廓检查。客户端未复验，JAR 未更新。
