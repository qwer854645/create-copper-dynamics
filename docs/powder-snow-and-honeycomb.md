# 细雪流体

## 细雪流体

注册 ID 为 `ccd:powder_snow`，并提供 `c:powder_snow` 流体标签。继承 Create `VirtualFluid`；管道、储罐、流体罐、移液臂均使用标准流体接口。仍用原版细雪方块和细雪桶，世界内不会出现另一种可蔓延的液体。

- 1 个原版细雪桶 = 1000 mB，可从储罐或工作盆手持取放，也可经分液池、分液漏斗自动装卸。细雪桶的流体接口同时可供 Create 过滤器采样。
- 铜桶可收取和放置原版细雪，每次 1000 mB；存有其他液体时不会覆盖已有内容。
- 直接对细雪方块接入泵可整块抽取 1000 mB；原生管口灌注会放置细雪方块。铜集液栅与智能集液栅可收取紧贴上方的一块细雪。整片固态细雪的区域抽取没有套用水源搜索。
- 满细雪炼药锅通过 NeoForge 原生 `CauldronFluidContent`／`CauldronWrapper` 接入，容量 1000 mB。按照原生整数步长逻辑，仅满锅可抽取，普通抽取不拆分三分之一桶。分液池消耗 1000 mB 将空炼药锅直接装满，保持桶与满锅的数量一致。
- 如果其他模组已在注册事件中为原版细雪炼药锅绑定流体，CCD 不再重复注册；该锅沿用已有绑定，不保证其流体身份等于 `ccd:powder_snow`。
- 集液栅继承炼药锅的降雪概率（每次有效降雪回调 10%），成功收集 333 mB；智能版沿用过滤和红石暂停。整数向下取整，不累计不可见的小数库存。
- 动力搅拌器：4 个雪球或 1 个雪块，无需加热，输出 1000 mB 细雪流体。没有额外注册冷冻加工体系；自定义雾化用途可继续使用 `ccd:atomizing` 配方和 KubeJS 接口。

流体外观直接引用原版细雪纹理，温度属性为 263 K。属性用于其他模组查询；不会据此每 tick 扫描环境或自行冻结周围方块。
