# 调频动力泵

原复进泵改名为调频动力泵，保留资源 ID 和 reciprocatingPump 配置键，以保留现有流量与距离配置。恢复单格结构和本体动力输入，移除两格上半部方块与方块实体注册。

主体铜壳，两端原生流体口，中部横轴齿轮，齿轮轴垂直于流体轴，顶部/底部露出轮齿。一份静态主体、一份原生动力泵齿轮派生 partial；各方向旋转复用。物品使用同一套主体与静止齿轮，补原生半轴，不再包含活塞、支架、连杆。沿用红石强度控制流速及距离、100 mB/t 分档、原有应力成本和放置对口逻辑。

便携泵保持原气囊造型与独立轮廓。旧模型只清除已失去注册与渲染引用的两格活塞资源；历史设计文档及预览不作为运行资源。

动力接入按用户补充改为原生小齿轮啮合：isSmallCog=true，hasShaftTowards=false，不再绘制或在物品中加入半轴。齿轮轴垂直于流体轴，使用原生 RotationPropagator 的小齿轮传动规则。便携泵明确覆盖为非齿轮并保留双轴，避免基类修改改变其动力接口。

资源引用、双语文本静态检查通过，未构建或启动客户端。旧存档中已放置的上半部方块不再注册，不提供自动迁移；新设计需重新放置。发布 JAR 未更新。
