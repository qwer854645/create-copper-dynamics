# PnP 3.2.1 元件适配复核

本轮只补 CCD 元件的专用身份和参数，不改变 Create 原生泵的 PnP 水轮机模式、液面、重力和吸程规则。

- 增压泵、两种转向增压泵：PnP 强度乘以 CCD 配置的压力倍率；转向拉取面继续使用真实相邻管口。
- 调频/便携泵：继续使用各自 flowPressure，红石零流量/零范围保持无驱动。机械泵身份不进入水轮机。
- CCD 泵与缓存出口：除了求解器分类，还限制 PnP 注入的内部 HydroTurbine 回调，避免内部回调与求解器身份不一致。原生泵不受影响。
- 缓存泵：有限储罐角色与可控出口，非普通透明泵；关闭功能时不追加压力水头。
- 创造输送储罐：修正 relay_endpoint 标签旧 ID，使用实际 creative_delivery_fluid_tank。
- 铜水槽/潮涌箱：无限端点；智能储罐、收集栅、雾化器、储罐燃烧室：有限储罐。
- 流体桥接/扩展代理：不标记为无限端点，保留真实来源有限库存。
- 三通阀：保留上一提交的立即失效与六面刷新。
- 万向泵：沿用真实多输入/输出边与专用求解端口映射，不改成单轴泵。

测试新增：八类 CCD 泵的内部水轮机排除、增压倍率、有限/无限角色、独立竖向调频输送。PnP 开启时这些测试及三通、万向/缓存等既有测试通过。全套仍有工作区原有 VariablePumpTransferTests.everyFacingTransfersAndSignalRestarts 失败：该测试包含从下方单格储罐顶面抽液，满罐液面恰与顶面开口齐平。PnP FluidPass.canDrawFrom 在 drawHead <= openingLip + epsilon 时拒绝抽取，不能为了让 Create 布置测试通过而绕过 PnP 物理规则。新竖向案例从上方储罐底部取液并向下输送，可正常通过。
