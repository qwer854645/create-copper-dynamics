# 铜供水箱：八棱罐身试版

本版重新设计主体轮廓：八边形铜罐身、略微外扩的深灰底座、顶部窄束口和固定铜顶板。保留简单的单方块体积；四个切角使用 Minecraft 原生支持的 Y 轴 ±45° 元素旋转。没有沿用前版的四角方框、内凹面板或箱子结构。

铜面使用自绘 16×16 连续明暗像素簇，色阶沿用 CCD 已有增压泵美术参考。body、cap、band、flat 四张贴图均为本项目自绘，不引入其他流体模组的代码或美术。深灰盖面使用相同颜色采样，重叠填充片不产生纹理差异；模型关闭环境遮蔽，避免这些片产生不同的顶面遮蔽结果。顶板与束口盖面相差一像素高度。

生成器为 `tools/create-copper-water-supply.cjs`，参数为本地 Create 源码与资源根目录；离线预览直接读取生成后的实际 JSON 模型。`outputs/copper-water-supply/preview.png` 展示正面、背面和顶面，`textures.png` 为最近邻放大的贴图。

这是主体造型试版。此前讨论的“仅在贴着有效容器的一面显示原生流体接口”暂未实现，待主体确认后再接入。供水速率、缓存、红石、无限水源行为以及现有完整方块碰撞均不改动。本次只做资源静态检查和离线预览，未构建或启动客户端。
