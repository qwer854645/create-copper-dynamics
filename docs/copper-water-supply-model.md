# 潮涌箱：铜框、四面玻璃与激活核心

原铜供水箱改名“潮涌箱 / Conduit Box”。外壳是铜底座、铜顶框与四根铜角柱，四面侧壁各安装一块玻璃。框架厚度为 2 像素，观察窗高宽均为 12 像素；玻璃只有细边和少量阶梯反光，中央透明，可从四面观察核心。顶面和内底面也使用铜材质，没有灰铁框。

body、cap、glass 均为 CCD 自绘 16×16 贴图，铜色阶延续已认可的增压泵风格；使用不规则的连续明暗像素簇。主模型使用 NeoForge cutout 渲染层并关闭环境遮蔽，方块注册添加 noOcclusion，避免玻璃箱遮蔽相邻表面。碰撞仍为完整方块。

先查阅本地 Minecraft 1.21.1 `ConduitRenderer`、`ConduitBlockEntity`、`ModelPart.Cube` 和原版纹理。游戏中的核心直接委托原生 `ConduitRenderer` 绘制，保留原版旋转外壳、浮动、水流动画和朝向玩家的眼睛，整体以 .55 倍缩入玻璃框内。`ConduitBoxRenderer` 持有一个无世界引用的纯显示对象，只提供激活、睁眼与旋转时间；不会注册或 tick 额外的世界方块实体，不触发潮涌能量、索敌、声音或伤害逻辑。红石继续只影响主动补水，显示核心保持激活外观。

物品模型使用原生 cage / open_eye 纹理与对应 UV，提供静态核心外观，四个方向都有眼睛，避免背包及掉落实体显示空箱。世界方块模型不含静态核心，避免与动态渲染重复。原版 blocks atlas 已包含 entity/conduit 目录，不需要额外复制纹理到 CCD。

生成器为 `tools/create-copper-water-supply.cjs`，参数为本地 Create 源码与资源根目录（含本地解包的原版 entity/conduit 参考纹理）。离线预览读取实际外壳 JSON，核心则用原生几何、贴图和一帧水流作定格示意；预览不是客户端截图，游戏中核心由原生渲染器绘制。临时水流预览模型在 finally 中删除，不进入项目资源。`outputs/copper-water-supply/preview.png` 展示正面、背面、顶面；`textures.png` 为三张 CCD 自绘贴图的最近邻放大。

保留现有注册 ID 和供水实现，本次不改变配方、容量、速率、能力缓存、红石暂停与容器交互。此前讨论的“接触有效容器的面显示原生流体接口”仍待后续接入。旧八棱罐身的 band 和 flat 贴图已移除。
