# 更多触媒新增五种介质

沿用 ProcessingMedia 注册源流体、流动流体、世界方块、静态桶物品、客户端颜色及公共流体动画、创造栏、JEI/EMI 可见性和介质 Ponder。所有桶沿用原版桶轮廓，只有新增桶的液面像素按介质颜色改色，未重生成已有用户美术。

- `ccd:withering_fluid` 凋零液：水 1000 mB + 凋零玫瑰 → 1000 mB；更多触媒 `withering`。
- `ccd:conduit_energy_fluid` 潮涌能量液：水 1000 mB + 鹦鹉螺壳 + 海晶砂粒 → 1000 mB；更多触媒 `tidal`。
- `ccd:moss_suspension` 苔藓悬浊液：水 1000 mB + 苔藓块 → 1000 mB；更多触媒 `mossify`。
- `ccd:tear_solution` 催泪溶液：水 1000 mB + 哭泣的黑曜石 → 1000 mB；更多触媒 `tear`。
- `ccd:corrupting_fluid` 腐化液：水 1000 mB + 凋零液 250 mB + 回响碎片 + 发酵蛛眼 → 1000 mB；更多触媒 `corrupted`。配方与处理需要更多触媒及铁砧工艺或 L2 敌对。

配方使用 Create 混合，受模组加载条件控制；所有流体身份保持稳定，创造栏沿用当前介质全部可见的规则。源流体与流动流体均加入更多触媒原生流体触媒标签，普通风扇和雾化器调用实际注册的上游处理类型，未复制物品加工配方。不存在上游类型时仍可作为 CCD 实体效果雾化介质。

世界接触／普通风扇附加效果：凋零液给予凋零；潮涌能量液给予水下呼吸与急迫；苔藓悬浊液给予自定义苔化；催泪溶液给予失明与虚弱；腐化液给予凋零与虚弱。雾化使用现有更强、持续更短的效果逻辑。普通风扇原生上游处理及实体行为保持继承。

苔化效果 `ccd:mossification` 使用原版盛开杜鹃花丛侧面像素图作为状态图标（Minecraft 原生美术资源）。持续期间每刻检查实体实际碰撞接触到的方块，包括脚下和侧面；只有原版 `minecraft:moss_replaceable` 标签目标会变成苔藓。上方为空时直接调用苔藓的原版 `performBonemeal`，继承扩散范围、随机植被和数据包生成规则；已有苔藓不会反复催生。接触效果 4 秒，雾化效果 2 秒；等级不扩大扫描范围，均只检查实体接触面。额外苔化接触测试与全套 89 项 GameTest 通过。

苔藓悬浊液自身也会处理六面相邻的合法目标，源液与流动液共用此规则。液体放置／邻居变化后调度一次固定六面检查，不扫描整片液体，也不每刻重复催生苔藓；共用上述原版苔藓替换与骨粉扩散实现。新增液体底部／侧面、源液／流动液及玻璃排除测试，全套 90 项 GameTest 通过。

验证：无附属、仅更多触媒 1.2.4 两种环境均通过 88 项 GameTest，包括桶流体能力、混合配方条件、源／流动标签、四种本体处理的风扇识别和雾化类型，以及五种介质效果的雾化强度／时长。更多触媒联测使用 NeoForge 21.1.264（其最低要求 21.1.220）。未安装铁砧工艺／L2 敌对实测腐化处理；也未完成新桶客户端视觉检查或每种上游物品配方产物联测。
