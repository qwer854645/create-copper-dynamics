# 独立流体理包机

新增 `ccd:fluid_repackager`，继承 Create 原生理包机的库存扫描、红石触发、朝向、动画与队列，只在自身构造函数中安装 CCD `CompositeRepackageHelper`。删除原先注入所有 RepackagerBlockEntity 构造函数的 RepackagerMixin，原版理包机保留原生 helper。

配方：原版理包机 + 流体管道 + 电子管，无序合成 1 台。当前直接引用 Create 理包机外观及渲染，不新画贴图。合并物品／流体订单时使用此设备；普通物品订单仍交由原生算法处理。

已有存档中的原版理包机不自动替换。原来承担 CCD 混合订单合并的机器需要玩家更换为流体理包机，避免继续使用不理解 CCD 流体组件的原生设备。不会自动迁移或破坏现有方块。

新增测试验证原版未安装 CCD helper、专用设备安装正确 helper、物品能力可访问。原有混合订单合并测试继续保留；完整游戏动画与收发待客户端查看。
