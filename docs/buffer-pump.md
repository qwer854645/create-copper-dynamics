# 缓存泵试作

新增 ccd:buffer_pump，底部 5/16 高度使用原生储罐压缩模型，上部铜泵体、前后流体口和左右轴。缓存容量 4000 mB，单种流体，保存与同步内容，渲染底部液位。物品包含静态半轴，各朝向共用主体。

按用户更正：绝不主动从邻接容器抽取流体，缓存由外部流体能力 fill 注入。动力只排出缓存，正反转选择前后排出端，速率暂按原生转速绝对值 / 2。暂停时保留缓存。原生透明管路行为关闭，防止绕过缓存。当前试作仅向相邻容器排出，远端管道压力尚未实现。

配方：动力泵 + 流体储罐。资源引用检查通过，未编译、运行测试或启动客户端，JAR 未更新。

用户更正后外观：上部采用 Create 原生 mechanical_pump 的端部与齿轮几何、pump 贴图，去掉原先自制铜箱泵体及前后双口，仅保留朝上管口。当前输出固定 UP，正反转都向上排缓存，禁止主动抽入。原生齿轮暂为静态模型，半轴仍动态显示；这是外观试作，后续需完善齿轮动画与远端管网压力。

距离更新：缓存泵范围取原版动力泵范围与当前配置增压泵范围的整数中点；默认倍率下为原版的 1.5 倍。沿顶部连通管路遍历并排到端点，遵守入口和出口通断及流体过滤，不经过其他泵、不加载区块，最多访问 4096 个位置。所有端点共享本 tick 的输出预算，不主动抽取任何容器。当前为直接端点传输，无原生管内流动动画。整数范围差不足 2 格时无法严格处于两者之间。

扳手更新：默认开口朝上，右键可旋转到六向；模型、齿轮、缓存液体显示与输出方向同步旋转，潜行扳手仍回收。继续只排缓存、不主动抽液。资源检查与编译通过，尚未在客户端复验。

放置更新：取消固定朝上，直接调用原生 PumpBlock.getStateForPlacement，使用动力泵原有放置朝向及水浸逻辑；输出继续跟随 FACING，扳手六向旋转保留。
