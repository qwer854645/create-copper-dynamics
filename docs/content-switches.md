# 独立内容开关

配置文件：`config/ccd-content.toml`。55 个独立布尔选项，默认全部为 `true`，无总开关、无分类开关。修改后重启游戏或服务器。服务端在玩家登录时同步生效值；联机以服务端为准。

每种设备、工具和加工流体各自一个选项。源液、流动液和流体桶共用该流体选项；铜/黄铜包裹尺寸变体共用对应材质选项；内部机械臂载荷和订单标记跟随所属设备。细雪开关仅控制 CCD 的流体支持，不删除原版细雪桶。

关闭内容后隐藏创造栏和配方浏览器条目、停用 CCD 自带相关获取配方，并阻止设备运行和正常使用。已有注册、方块、物品、储液及包裹仍保留，拆机/扳手回收路径不清除库存。重新开启后沿用原有实现。依赖关闭内容的 CCD 配方也会停用；不会修改其他模组的配方文件。

配方条件必须在数据加载前读取，因此本配置使用 COMMON 启动配置，而非晚于配方加载的 SERVER 世界配置。普通风扇仅额外排除已关闭的 CCD 流体，原生催化剂和开启流体沿用原查找。已存在的世界流体仍保留原版流动/物理行为，不删除世界中的液体。

验证：默认全开 129 项基础 GameTest 通过；使用实际配置关闭熏烤液再次启动，129 项通过，确认其配方、风扇催化和雾化选择停用。缓存泵关闭时能力不可用、已有 1000 mB 保留，重新开启内容不变。未做全部 55 项开关组合或客户端 JEI/EMI 联机重连实机矩阵；浏览器插件有各自的运行期缓存生命周期，需客户端验收。
