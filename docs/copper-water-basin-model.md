# 铜水槽：素面柜体与铁质银边

下部为完整的铜色柜体轮廓，没有柜门、门缝、柜门把手或家具式饰框；顶部为铁锭贴图风格的明亮银色包边，围住居中 12×12 槽口。按用户后续要求，后沿安装本模组铜龙头的缩小版，不增加储物库存或独立开关操作。

水槽本体保留 14 个长方体：底部内收、柜体兼槽底、四壁、四条包边以及四片下部收口，本体位于 X/Y/Z=0..16。包边在 Y=15..16，四边宽度均为 2；槽口为 X/Z=2..14。槽底在 Y=9，下层 Y=9..11 收进一像素，形成 X/Z=3..13 的 10×10 盆底。水面仍在 Y=14。

龙头直接复用 `ccd:block/faucet_open` 的全部八个元素，所有坐标和旋转中心等比缩小为 .5，再平移 [4,17,1.5]，UV 和面贴图布局不改。它保留原有铜弯管、Create 原生管口和分液池喷嘴、灰色手柄，取开启状态作为固定外观。添加一块安装座与一段铜立管承托背部水平输入；总模型共 24 个构件，最高 Y=24。只有实际内嵌管口的 cullface 被移除，避免相邻方块裁掉水槽上的小管口。喷嘴朝下并位于槽口内，底部 Y=17.5，高于槽沿与水面。

四张贴图均为自绘 16×16 像素图：outer 铜柜体、rim 银色包边、inner 灰色内壁、floor 槽底。铜面延续用户认可的连续明暗像素簇，四面不绘制门缝或把手。原版 1.21.1 本地 iron_ingot.png 仅用于观察中性灰白色阶及铁锭折边表达：银边采用银白亮面、白色短高光与少量浅灰折边，按用户补充减少深色面积并提高阴影亮度，取消先前偏绿的工业灰。实际像素布局重新绘制，没有将原版物品贴图直接铺到方块上，也没有使用外部模组贴图。参考图片不打包进项目。

包边四个上表面按模型 X/Z 绝对坐标取同一张图集，转角连续。柜体各拼接面的铜贴图也使用绝对坐标，避免在上部槽壁与下部柜体之间形成假的柜门或分板缝。灰色槽壁与下层收口使用对应位置的 UV，保留一条窄的内嵌暗缝。旧 front 和 metal 贴图及其引用已清理。

`CopperKitchenSinkBlock` 继续继承既有 `CopperWaterBasinBlock` 的水源及手持交互，只同步更新形状到当前 24 个构件；保留四向放置、旋转/镜像及扳手旋转。槽内凹陷没有被完整方块碰撞填住。物品 GUI 比例调整为 .55 并下移 1，容纳高出柜体的缩小龙头。供水箱的父类与独立模型不改。

`CopperWaterBasinRenderer` 不改：调用 Create 原生 FluidTankRenderer 前平移 Y=6.5/16，再将 Y 缩放为 .625；原生满水 Y=5..12 映射到 Y=9.625..14，处于槽底之上、包边之下。实际水贴图、颜色、动画、容量和无限取水行为都继续沿用现有实现。普通右键装水、潜行右键销毁输入流体等规则不改，供水箱也保留独立模型与父类行为。

生成器为 `tools/create-copper-water-basin.cjs`，参数为与其余离线工具相同的 Create 源码根目录。`outputs/copper-water-basin/preview.png` 展示装水、空槽结构和背面；空槽只用于查看形状，不是游戏内可用状态。`textures.png` 展示四张自绘图集的最近邻放大图。水面仅作离线示意，没有写入静态资源模型。
