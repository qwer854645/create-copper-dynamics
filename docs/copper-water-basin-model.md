# 铜水槽厨房造型

按用户要求，铜水槽改为厨房水槽样式：槽体高 8 模型单位，厚 2 的底板，左右及前部平整槽沿，较宽的背部台面承托一根铜龙头，末端为灰色短出水嘴。共九个简单长方体，不添加阀门动画、铆钉或复杂弯曲几何。槽底有 3×3 像素的排水口细节；这只是贴图，不新增排水规则或独立库存。龙头不设单独开关。

四张 16×16 贴图采用 pixel-art 工作流，沿用 CCD 已认可的铜色阶与 `faucet/body` 的连续像素簇，分别表示外壁、较暗内壁、槽沿和槽底。明暗边缘用于表示折边，不用渐变、抗锯齿或排列的小铆钉。喷嘴复用 CCD 移液臂的灰色金属与深色孔内贴图，不引用第三方模组资源。

`CopperKitchenSinkBlock extends CopperWaterBasinBlock` 只增加厨房外形的四向放置、结构旋转/镜像、普通扳手旋转和对应碰撞。物品仍叫铜水槽，注册 ID、方块实体、配方、掉落、固定水库存与取放行为不变。普通右键填充水、潜行右键销毁输入流体、拆除不保留液体等规则均由原父类处理；潜行扳手回收继续使用原生机制。供水箱继续直接继承旧父类并使用自己的模型和形状，不获得厨房造型或朝向属性。

默认模型正面朝 SOUTH，背后龙头位于北侧。放置后正面朝玩家，模型及 VoxelShaper 的四向映射均为 SOUTH=0°、WEST=90°、NORTH=180°、EAST=270°。普通扳手每次顺时针旋转 90°；不再调用原生储罐的切换窗口操作。选取与碰撞包含槽底、四壁和龙头，但保留槽内凹陷。

`CopperWaterBasinRenderer extends FluidTankRenderer` 只在调用父类前将 PoseStack 的 Y 缩放为 .5，随后恢复。仍由 Create 选择实际水纹理、颜色、动画与液位；满水时原生水面模型 Y=12 缩为 Y=6，低于 Y=8 的槽沿，底面 Y=5 缩为 Y=2.5，高于 Y=2 的槽底。六面标准流体能力、容量与无限供水不受视觉缩放影响。

生成器为 `tools/create-copper-water-basin.cjs`，使用与其他离线预览工具相同的 Create 源码根目录参数。`outputs/copper-water-basin/preview.png` 展示正面、用于查看结构的空槽和背面。空槽不是可用状态，游戏内仍固定有水。蓝色水面为离线示意，未嵌入静态模型，物品也不伪装携带一份可提取的水。

本次进行静态代码/资源核对与离线模型渲染，未构建、测试或启动游戏。水槽几何及四张铜材质贴图为 CCD 自有美术；渲染机制直接复用原生 Create 实现。
