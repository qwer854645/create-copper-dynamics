# 铜水槽现代柜式造型

仅参考 Cooking for Blockheads 官方水槽模型的结构构成与整体比例：完整柜体、独立台面、内嵌槽盆及细龙头。参考链接：[官方模型](https://github.com/TwelveIterations/CookingForBlockheads/blob/26.3/common/src/main/resources/assets/cookingforblockheads/models/block/sink.json)。不使用、临摹或参考其贴图；没有将对方的模型 JSON、几何元素或美术文件复制进本项目。

CCD 模型重新绘制为铜色双门柜体、铜色折边台面、内嵌金属槽盆、金属细龙头、单侧混水柄及两根柜门把手，共 17 个简单构件。台面 Y=15..16，槽底 Y=9，水面 Y=14，龙头最高 Y=21。背后龙头低于一格半高，柜体占一格；柜门、混水柄与排水口仅为外观，不添加储物库存、独立开关、加工或排水机制。

六张贴图均为 CCD 自行绘制的 16×16 像素图：铜侧壁、双门正面、金属内壁、台面、槽底及龙头金属。按用户认可的增压泵风格重新手绘 14×14 的不规则连续像素簇并加一像素折边，使用既有 CCD 铜色阶；没有把 faucet/body 的像素直接复制到这版。正面取消家具式内嵌装饰框，只保留折边、短磨损和单条门缝。顶部台面单独绘制铜色像素簇与亮暗折边，使用与柜体一致的铜色阶，不再使用银灰台面。槽盆内部、细龙头和把手仍使用接近原生工业铁的六级灰色，保留成片高光与凹槽阴影。细龙头和把手的 UV 移入灰色图集的材质区域，避免只取到外缘同一色条。没有采样参考模组的图片、纹理色板或材质布局。喷嘴孔底仅复用本项目已有的深色贴图。所有像素均为整数绘制，不使用渐变、抗锯齿、棋盘噪点或密集排列的铆钉。

`CopperKitchenSinkBlock extends CopperWaterBasinBlock` 只提供造型对应的四向放置、碰撞、旋转/镜像及普通扳手旋转。默认正面 SOUTH，背后龙头在北侧。放置后正面朝向玩家，模型和 VoxelShaper 的四向映射为 SOUTH=0°、WEST=90°、NORTH=180°、EAST=270°。普通扳手每次顺时针转 90°；潜行扳手回收仍使用原生机制。碰撞与 17 个几何构件逐项一致，槽盆内部保持凹陷。物品 GUI 单独缩小至 .55，容纳高于柜体的细龙头。

`CopperWaterBasinRenderer extends FluidTankRenderer` 只在调用原生渲染器前平移 Y=6.5/16，再按 Y=.625 缩放，之后恢复 PoseStack。满水时原生水体 Y=5..12 对齐到 Y=9.625..14，高于 Y=9 的槽底并低于台面。仍由 Create 绘制实际水纹理、环境颜色和动画。库存、容量、抽取和输入销毁不受视觉变换影响。

无限纯水库存与手持容器交互仍完全继承旧父类和原方块实体：普通右键装水，潜行右键销毁输入液体，不误清空手持容器。注册 ID、名称、配方和掉落不改。供水箱仍直接继承旧父类，保留独立模型与完整方块形状，没有获得本次柜式造型或朝向属性。

生成器为 `tools/create-copper-water-basin.cjs`，参数为与其余预览工具相同的 Create 源码根目录。`outputs/copper-water-basin/preview.png` 展示正面、水面示意、用于观察槽体的空槽以及背面；`textures.png` 是六张自绘贴图的最近邻放大图。空槽不是可用状态，游戏内仍固定有水。离线示意水面不写入资源模型，物品也不会伪造一份可提取库存。

本次仅进行静态代码与资源核对、模型离线渲染，未构建、测试或启动游戏。柜式构成参考已注明来源；最终几何与全部水槽贴图均由 CCD 自绘，原生水面渲染直接复用 Create。
