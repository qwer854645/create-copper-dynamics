# 思索

使用 Ponder 1.0.82 的原生插件和 CreateSceneBuilder；客户端初始化时注册，不增加独立教程界面。标题、文字、框选、交互图标和时间轴均沿用原生组件。说明保持短句，每段对应一个连接或操作，不添加开发细节。

本轮十个场景：

- 流体的打包与解包：连接方向、红石打包、运输、解包、过滤和同订单理包。
- 通过流体舱口存取流体：手持存取、智能过滤和移液臂目标选择。
- 扩展与合并流体存取：单容器端口、禁止端口串接、双端桥接与过滤。
- 组合智能储罐：共享容量、截面尺寸、横向连接与观察窗。
- 使用龙头倾倒流体：背面供液、正下方容器和下方两格物品加工。
- 使用流体雾化器加工：背面接动力、侧面接液、手持存取与红石暂停。
- 切换流体通路：三通阀公共口、直通／侧通和泵送方向。
- 收集与供应流体：集液栅下排、智能控制、潮涌箱与铜水槽。
- 在容器之间输送流体：传输器方向、扳手反向与红石暂停。
- 使用增压泵输送流体：管路、方向、扳手反向与应力。

同操作的尺寸变体共用场景。未给红石阀门、桶、材料等制作重复教程；流体仪表暂未注册思索，避免把未演示网络设置的打包场景当作仪表教程。

基座结构为 CCD 自建 5×5×5 模板，由 `tools/create-ponder-resources.py` 生成 NBT 与双语文字。方块逐步显现、容器库存和包裹状态由故事板分步设置，不依赖实时自动化推进。场景目前演示关键连接与状态，尚未完整演示移液臂抓取动画或蛙港完整运输。

构建、语言参数与模板静态检查通过。未运行客户端逐场景播放；实际镜头、指示框遮挡、动画时序以及虚拟世界多方块渲染仍需播放验收，不能将 API 编译通过等同视觉验证。
