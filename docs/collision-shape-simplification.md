# 碰撞与选中形状简化

按用户要求，移液臂不变，碰撞、准星选中和交互形状使用一致的粗略形状。显示模型不改。

- 铜水槽：25 → 6 个实际 AABB，槽底四壁加粗略龙头范围，保留槽内空腔。
- 普通／智能集液栅：18／21 → 6，栅条合并成顶部连续薄面，侧壁统一，不单独计入过滤面板。
- 普通／智能龙头：11／17 → 6，按安装座、主体和出液嘴概括，不随把手开关细分形状。
- 红石流体阀：5 → 1，按各原生状态的外接盒缓存。

盒子数来自运行时 `VoxelShape.toAabbs()`，不是构造时输入盒子数量。所有形状预先缓存，未加入逐 tick 计算。新增测试遍历这些设备的全部状态，验证碰撞、选中、交互形状完全相同；全部 39 项 GameTest 通过。

简化会填入部分原模型细小空隙，精细把手和面板周边也由主体范围选中。此修改减少形状复杂度，未通过性能采样量化帧率收益。
