# 提示与思索核查

第二轮精简：同类泵统一“使用旋转力…输送流体”，条件栏只描述信号、接口等差异，避免重复摘要。移除通用拆卸说明、显而易见的“其他面保持原样”和重复供能说明。铜／黄铜桶的取液、倒液、世界交互文本共用措辞；横向／竖向储罐共用取液说明；龙头共用红石暂停说明。创造储罐准确区分选液与模式控件；调频泵补充侧面指针显示红石信号。清理旧版属性过滤器取反快捷键提示。中英文提示键、成对段落、连续编号及强调符号检查通过，未启动客户端或更新 JAR。

对照 Create 的 ItemDescription 格式，使用摘要、条件／行为与操作／结果配对；下划线仅包围需强调的关键词，按功能解释与操作指引组织文本。保留原生 Shift 描述与动力统计提供器。

补齐过滤器、缓存泵、创造储罐、载荷提示；修复便携泵中文问号乱码。完善新泵、流量计、万向泵、超级熔岩的操作与限制。大容量桶不再以固定桶数描述容量，避免配置改变后失实。可选介质明确注明需要对应加工附属，显示可见不代表加工类型可用。

新增泵连接方式、缓存输送、万向泵接口、流量测量、红石阀门、流体过滤、大容量桶、加工介质与流体订购思索。47 个基础物品入口有中英文摘要与思索注册。金属包裹尺寸变体复用对应包裹翻译 ID 与打包场景。流体方块没有单独的 BlockItem，其说明由桶提供。

`tools/update-help-text.py` 写入本轮整理的双语文本，`tools/audit-help-text.py` 只读检查注册物品摘要覆盖、思索注册入口、场景文字键、提示配对与强调标记，避免后续新增物品静默缺失说明。

验证：Java 编译通过；文本覆盖检查通过。未启动客户端，新增场景播放、长文本换行与实际视角尚未复验。场景为分组教学，不是每种物品都有独立专属动画；加工介质和包裹等复用教学主题。JAR 未更新。
