# 提示与思索核查

对照 Create 的 ItemDescription 格式，使用摘要、条件／行为与操作／结果配对；下划线仅包围需强调的关键词，按功能解释与操作指引组织文本。保留原生 Shift 描述与动力统计提供器。

补齐过滤器、缓存泵、创造储罐、载荷提示；修复便携泵中文问号乱码。完善新泵、流量计、万向泵、超级熔岩的操作与限制。大容量桶不再以固定桶数描述容量，避免配置改变后失实。可选介质明确注明需要对应加工附属，显示可见不代表加工类型可用。

新增泵连接方式、缓存输送、万向泵接口、流量测量、红石阀门、流体过滤、大容量桶、加工介质与流体订购思索。47 个基础物品入口有中英文摘要与思索注册。金属包裹尺寸变体复用对应包裹翻译 ID 与打包场景。流体方块没有单独的 BlockItem，其说明由桶提供。
