# 模型一致性检查

检查全部本地普通模型继承、纹理变量和元素旋转，覆盖 198 个解析后模型及 504 条 blockstate 模型引用。NeoForge 自定义 bucket loader 不作为普通几何模型处理。反向包裹内衬、雾化器内壁等保持原设计，不把 signed bounds 一律归正。

修正：

- 红石双向泵 UP/DOWN 模型旋转互换，动态指针变换同步，确保出口与 FACING 一致。
- 转向与双向动力泵的 cross/reversed_cross 从各自正向/反向主模型派生，消除独立编辑后几何和 UV 漂移；保持现有四份基础模型数量。
- 三种泵的物品主体从当前方块主体同步，保留必要静态轴和指针；三通物品主体/管口重新组合当前默认 SOUTH/roll=0 的实际资源，避免仍用旧铜色主体而世界用原生管体材质。
- 缓存泵齿轮回到原生轴中心 y=8，物品与动态旋转中心同步。

自动断言：两种泵共 96 个方向/反向状态的旋转基准符合运行时 FACING/ROLL；五种泵物品主体与方块元素及材质绑定相同。资源引用检查、Java 编译通过。

限制：全资源引用有效不代表全部设备每种外观状态均已实测；原生动态模型、Flywheel、玻璃透明层级及物品显示变换仍需客户端目视确认。未运行客户端或更新发布 JAR。
