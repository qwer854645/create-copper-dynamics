# 泵接口放置对齐

CCD 的增压泵、转向增压泵、双向动力泵、红石双向动力泵、便携泵、复进泵、缓存泵共用 PumpPlacement。优先识别被点击邻居朝向新位置的物理流体口，其次按观察方向寻找邻接管道。原生管道可在放置后长出连接臂；其他运输行为按 canHaveFlowToward 判断。现有泵只认管口，不把轴孔或封闭面当流体接口。

直通泵自动对齐流体轴；转向泵将被点击连接作为后端，选择能连接第二相邻管道的出口/ROLL；缓存泵单口朝向连接面。便携泵及两格复进泵保持水平流体轴，不自动倾倒机体。放置无匹配时保留原有方向规则。只改变新放置方块，不旋转已有邻居。原生 PumpBlock.isOpenAt 对缓存泵改为实际单口，便于原版管道正确连接。

新增两项 GameTest 通过，覆盖七种泵对邻接泵口的可用方向以及原生管道放置。全套测试仍有三项失败：智能集液栅轮廓简化检查，以及此前两格复进泵上半部的标签和独立回收检查。未修改这些无关问题。客户端光影模组测试后已恢复，JAR 未更新。
