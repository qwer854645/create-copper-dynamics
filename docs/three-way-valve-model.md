# 红石三通阀模型

沿用已确认的增压泵风格：原创 16×16 不规则铜色像素机壳，保留 [3,3,3]–[13,13,13] 主体。未接管的三面为完整铜壳，不加入传动轴口、仪表盘、铆钉或储液显示。

三个管口统一使用 Create 6.0.10-280 原生流体管口。按六个方向分别导入 `fluid_pipe/rim_connector` 与 `rim` 的几何、UV、旋转和裁切设置，替换旧的自制四条方环；不再把公共口整圈染银、选通口整圈染绿。

保留原有公共／选通／关闭角色模型和 multipart 选择规则。三份 32×32 管道图集均来自 Create `pipes.png`，每张仅将管口端面上四个像素改为小色标：浅色为公共口，绿为选通，红为关闭。其余像素及全部透明度保持原值，管口侧边不变。标记表示端口角色与当前通路，公共口允许双向流动，不画单向箭头。

`FACING` 的反向仍是公共口，无红石接直通口，有红石接 `ROLL` 决定的侧口。全部六向、四种滚转、含水、红石、旋转、镜像及管网逻辑均未修改。新静态子模型已完整包含原生端圈和连接段，因此取消三通专用的 `PipeAttachmentModel` 包装，避免在开放端叠画同一原生管口而产生深度冲突、遮住色标；此改动仅影响外观。物品模型对应默认南向、roll=0、无红石状态。

`tools/create-three-way-valve.cjs` 接收解压的 Create 源码根目录，生成 19 个方块子模型、物品模型、四张贴图及 `outputs/three-way-valve/preview.png`，展示直通、侧通与侧通背面。仅静态检查及离线渲染，未构建或启动游戏。
