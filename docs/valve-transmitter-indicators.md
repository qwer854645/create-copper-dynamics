# 三通阀与传输器指示修正

三通阀保留两个相对空闲面的仪表，指针使用 Create 原生 fluid_valve 指针区域，不再使用低对比度工业铁色块。红石仅切换指针，不改变管口颜色：公共口、直通口与支路口保持各自未通电时的材质。通路逻辑不变。

传输器红条位置按导入贴图实际 x=2..3、12..13 / y=2..6 修正；之前 x=1..2 的范围会改动边框并漏掉一列。新状态图严格只改红条像素，边框和其余贴图保留。三角方向改为 lower_bowl 四侧 UV 旋转 180°，直接影响当前模型取样，不再依赖重复翻转源贴图。

验证：12 个传输器状态完整、同状态左右红条像素一致；三通所有非仪表部件不再带 powered 条件，96 个双面仪表部件保留。资源引用检查通过，离线预览已更新；尚未游戏内观察两面指针和方向图案。

fix-valve-transmitter-feedback.py 是一次性迁移，包含 UV 相对旋转，不应重复运行。旧 create-three-way-dial.py 会重建原先通电变色的分支条件，不应再用于覆盖当前模型。
