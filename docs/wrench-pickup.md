# 原版扳手拆卸

所有 21 种 CCD 实体设备加入 Create `wrench_pickup` 标签；流体方块不加入。现有设备已通过父类或 IWrenchable 实现原生潜行右击拆卸，不复制原版移除、破坏事件和掉落逻辑。

修正普通／智能龙头的无物品回退：手持扳手时不切换开关，让交互继续到扳手。移液臂手持扳手时不优先卸下携带流体。普通右击旋转／切换观察窗等原有行为保留。

运行测试直接调用原版 WrenchItem.useOn：20 种设备逐一拆除且向玩家返还对应物品一次；流体仪表两面板依次拆下，回收两个 CCD 仪表，最后面板拆下才移除方块。另验证标签覆盖全部实体设备，46 项 GameTest 全部通过，构建成功。未测试每种设备带满库存／流体时的拆卸，内容处理继续遵循原有破坏规则，不承诺保存内部流体。
