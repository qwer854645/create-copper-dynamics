# 红石双向动力泵

`ccd:redstone_fluid_pump` 继承原生 PumpBlock/PumpBlockEntity。无信号沿 FACING 排出，接收任意强度红石信号后反向；旋转动力仍必需。只覆盖 isPullingOnSide，原生管路搜索与两端压力使用相同抽排角色；压力大小、范围与应力沿用动力泵，不应用增压泵倍率。

两个相对的非流体面连接传动轴，流体轴为 X 时轴接口在 Z，流体轴为 Y/Z 时轴接口在 X。非小齿轮。机壳参考红石阀门，直接使用原生阀门轴孔和管口贴图；单面仪表仅一个指针，红石切换后转动 180° 表示相反流向。指针不表示流量。

配方：动力泵 + 红石流体阀 + 传动轴，无序合成。已加入创造栏、挖掘与扳手回收标签。物品模型包括固定指针。

47 项 GameTest 与构建通过，包含六向红石抽排反转、两轴孔与流体口不重叠，以及新增设备扳手回收。离线预览不含运行时旋转轴，实际管路流量和动力网络接入还需完整运行验证。

后续模型修正：显示名称改为红石双向动力泵，资源 ID 不变。指针从 7 像素缩短为 3.5 像素，从仪表中心指向一侧，仍按红石状态旋转 180°。底面改为不透明铜壳，仪表盘下增加不透明底板，避免透明开口透视内部。物品模型改用 Create 普通机械方块显示变换，并包含沿 X 轴的两个原生半轴。现有贴图未改写。

本次模型修改通过资源引用和中英文文本静态检查，并生成包含两个指针状态、物品轴和封闭背面的离线预览。按项目默认约定，本次未构建或启动客户端，手持尺寸与世界内显示尚需复验，JAR 未更新。
