# 黄铜包裹自动拆分

CCD 流体打包机后方的目标面提供物品接口时，接收黄铜包裹并把普通物品放入该接口，流体按每个铜包裹最多 4000 mB 分装，从打包机原生输出队列送出。不同流体及组件分别保留，铜包裹继承黄铜包裹的地址；拆分后不沿用已消费的混合订单分片信息。

后方仅提供流体接口时，继续直接卸液。后方同时提供物品和流体接口时优先拆分，无需模式切换。

模拟接收要求所有物品能够放入。目标在模拟后发生变化时，实际未放入的物品保存在机器内并重试；已分装的液体不再进入恢复包裹。输出铜包裹使用 Create 已有的队列保存、输送和拆机掉落流程。仅修改 CCD 流体打包机，不修改 Create 原生设备或补丁。

验证：123 项基础 GameTest 通过，新增覆盖多种流体分包、地址、模拟无副作用、满箱等待、执行余量重试、保存重载及拆机掉落。未进行客户端视觉验收，未更新发布 JAR。
