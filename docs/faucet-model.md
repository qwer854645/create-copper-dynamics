# 铜龙头模型

延续用户认可的增压泵风格，使用 16×16 原创铜色与深灰手柄贴图，手工安排不规则连续像素簇，不添加铆钉或精细装饰。保留背后取液、向正下方出液的造型，手柄横向为开启、纵向为关闭。

背部直接使用 Create 6.0.10-280 的 `fluid_pipe/rim_connector/north` 和 `rim/north` 原生管口；下方直接复用分液池的 `spout/middle`、`spout/bottom`，整体上移 8 模型单位，保留其原始尺寸、原有面的 UV、裁切设置及喷嘴纹理。原生中段原本与分液池上段相接；用于较窄的龙头弯管时，额外补一张顶部面，沿用该中段底面的原生 UV，封闭露出的肩部空隙。喷嘴出口中心仍为 [8,1,8]，与旧模型一致。铜制弯管连接背部原生管口与喷嘴，手柄由铜制阀杆连接，阀杆在手柄底面结束，不产生重叠侧面。

只修改基础龙头的开／关模型和新增贴图，现有物品模型继续继承关闭模型。方块状态仍按 OPEN 且非 POWERED 选择开启模型，其余状态选择关闭模型；四个水平朝向、含水、手动开关、红石暂停、抽灌周期及流体逻辑不变。

智能龙头原有父模型引用会自然继承这套几何，其黄铜主体材质覆盖和过滤行为不变；本次保留弯管前端 Z=10、Y=7–11 的空间，现有过滤图标位置 [8,8,10.4] 不会埋入弯管。智能版独立面板美术留待下一项，不将其作为已完成的智能版重制。

`tools/create-faucet.cjs` 接收解压的 Create 源码根目录，生成两种状态、两张贴图及 `outputs/faucet/preview.png`，展示关闭、开启及下方喷嘴。`textures.png` 展示铜面与手柄。只做静态检查和离线渲染，没有构建或启动游戏。
