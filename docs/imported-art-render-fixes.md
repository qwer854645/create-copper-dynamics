# 导入美术后的显示修正

- 流体理包机使用 CCD 自有 cutout_mipped 模型引用，动态舱门也仅针对该设备从 solid 改为 cutout_mipped，避免透明开口绘成黑面。
- 传输器共用模型绕 Y 轴旋转 180°，物品与六向方块均使用同一资源。
- 红石阀盘面恢复到机芯外侧 14.01/1.99，玻璃边框在 14.12/1.88；指针同步恢复外移比例，避免盘面被不透明机芯遮挡。
- 智能集液栅面板外移至外壁外侧，过滤交互中心置于 z=16.0625；物品同步采用相同面板。智能舱口按导入槽框的中心和倾角修正过滤显示偏移。
- 移液臂 partial 和物品模型声明 cutout，普通 ArmRenderer 的 solid 分支仅对 CCD 移液臂切换 cutout；Flywheel 使用 partial 自身材质层。需要游戏内分别验证两种渲染路径。
- 潮涌箱物品框架改为继承当前方块框架，智能集液栅物品主体与面板同步；未承诺所有动态物品姿态与放置模型完全相同。

资源引用检查及 46 项 GameTest 通过。独立客户端启动并强制加载 ArmRenderer、PackagerRenderer 成功，无注入异常；该检查不包含世界内截图或过滤图标、液体和运动动画的实际观察。最后微调舱口偏移后需重新构建。

fix-rework-rendering.py 是一次性导入迁移脚本，包含转向和相对位移，不应重复执行；后续预览应只读当前资源。
