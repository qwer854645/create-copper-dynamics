# 卧式活塞泵外观试作

复进泵新增独立卧式主体，包含铜泵缸、导轨、滑动活塞、外置连杆和小曲柄。主体只一份，通过方块状态水平旋转；三个动态部分单独建模用于移动和旋转。物品展示由同一套部件组合。

复进泵切换到 PistonPumpRenderer，按曲柄角计算滑块位置及连杆角度。气囊模型仍由便携泵使用；便携物品不再继承复进泵物品，避免复进泵造型变化影响便携泵。

这是外观试作，资源引用检查通过并生成双视角预览。未编译或启动客户端。曲柄与原生半轴衔接、全行程下连杆/缸体间隙仍需进一步设计与世界验证，不能视作最终机械结构。

简化版：移除外露曲柄、连杆、导轨、大底座及对应两个 partial 文件。保留前方铜泵缸、后方封闭传动壳，中间开口露出带黄铜套环的活塞杆。只有共享主体和一个活动活塞模型；活塞沿管路方向往复，内部偏心机构不再单独绘制。便携泵不受影响，资源引用检查通过，未进游戏验证。

最终试作布局按用户新方案：完整铜主体，前后流体口、左右轴孔，顶面中央黄铜导向座及竖直灰色推杆，顶端薄黄铜压头。推杆垂直于流体轴与动力轴组成的平面，上下行程 3 像素，最低位置与导向座保持 0.25 像素间隔。主体上表面与管口连接器错开 0.01 像素避免共面。模型仍仅主体和一个活动推杆；未启动客户端或更新 JAR。
