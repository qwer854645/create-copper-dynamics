# 便携式流体泵

新增 ccd:portable_fluid_pump，共享现有复进泵气囊、底座、踏板及物品展示模型，没有复制几何。原复进流体泵保留红石调速/距离功能，造型暂共用，待后续重新设计。

便携泵有横向双轴，可接受应力驱动，应力成本与原版动力泵一致。没有有效外部转速时，空手右键提供 10 tick 手动运行；持续右键刷新时间，潜行右键反向。手动只提供内部泵送压力，不生成外部动力。过载时不通过手动绕过。手动状态只同步客户端，不持久化到存档。

portablePump.flow 默认 300 mB/t，配置值四舍五入到 100 mB/t 的整数倍，最低 100；portablePump.range 默认单侧 4 格。无红石分档调速。流速按原生压力映射，为单路目标值，仍受管路分支和端点能力影响。机械驱动时沿用 FACING 流向，手动反向只在手动运行期间生效。气囊动画同时支持机械和手动状态。手动操作沿用曲柄的 32 RPM 饥饿消耗倍率。

配方：动力泵 + 手摇曲柄 + 传送带。资源引用和双语文本静态检查通过。未构建或启动游戏，实际手动输送和动力切换尚待运行验证，JAR 未更新。
