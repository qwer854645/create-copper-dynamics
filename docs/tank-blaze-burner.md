# 储罐烈焰人燃烧室

`ccd:tank_blaze_burner` 继承 Create BlazeBurnerBlock／BlazeBurnerBlockEntity。保留固体燃料、供热等级和原生燃烧计时，增加 4000 mB 单流体储罐，六面提供流体能力，移液臂无需舱口直接操作实际储罐。

每 10 tick 尝试按桶供燃，原生 tryUpdateFuel 模拟与执行均通过后才扣除 1000 mB。支持普通熔岩、超热介质及对应桶被原生／附属燃烧逻辑认可的流体；拒绝水，不混合燃料。储罐可排空，便于更换燃料。第三方无桶液体、专有化学品和仅提供独立燃料 API 的实现未保证支持。热量暂满时普通熔岩和超热介质仍可存入；其他特殊燃料是否能预存取决于原生桶燃料判定。

底部原生单储罐 JSON 压为 4/16 高，保留 UV；上部使用 Create 原生 blaze_cage OBJ，Y 转换为 4/16 + 原 Y × 0.75。动态烈焰人渲染使用相同变换。原生 cage 最高 Y 为 15/16，组合后最高为 15.25/16，不超过一格。引用模型和纹理来自 Create，非原创美术，沿用上游资源许可。离线预览只绘制静态模型，不包含动态烈焰人。

合成：原生烈焰人燃烧室 + 流体储罐 + 流体管道 + 铜板。新增中英文提示、思索、掉落与扳手拾取标签。已有物品中键与蓝图材料需求适配为新方块自身。

94 项基础 GameTest 通过，包括移液臂直连实际储罐、模拟无副作用、拒绝水、储液保存、自动扣液供燃和热量状态；后续放置朝向／蓝图覆盖与思索代码编译通过。未启动客户端验证复合 OBJ 模型加载、完整燃烧动画及每种第三方燃料。JAR 未更新。
