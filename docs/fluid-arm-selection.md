# 移液臂目标选择对齐

FluidArmItem 改为继承原生 ArmItem。目标仍按方块与点击面存储，以遵守流体能力的面向限制；不能调用原版物品目标的放置配置包，因此覆盖该回调，只应用已经由普通交互包同步至物品的 CCD 选择。

右击现在在取液／注液间循环，第三次右击不再取消。左击移除被选方块的所有面，并取消本次方块攻击；可用目标也禁止由手持移液臂破坏。原有对已放置移液臂应用／清空配置入口保留。

同时修复位置标签读写不一致：NbtUtils.writeBlockPos 写入 INT_ARRAY，原先读取按 COMPOUND 检查会跳过目标；改用 NbtUtils.readBlockPos 对应读取。

新增有效舱口目标测试：连续四次右击的模式循环、选中目标不可攻击、取消后选择为空。全部 43 项 GameTest 通过，构建成功。客户端高亮和实际鼠标事件仍需游戏内查看。
