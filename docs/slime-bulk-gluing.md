# 史莱姆流体与批量粘接

`ccd:slime`／`ccd:flowing_slime`／`ccd:slime_bucket`：独立可用的绿色流体，支持桶装、管道和雾化器。搅拌一个粘液球得到 250 mB，保持每桶对应四个粘液球的换算。

`ccd:bulk_gluing` 使用 Create 原生风扇加工接口。气流经过世界中的史莱姆流体，或由雾化器消耗史莱姆流体时，触发相同加工类型。

读取当前 RecipeManager 中的工作台配方，不维护独立手工粘接表：要求配方恰有两个非空原料槽，一个匹配待加工物、另一个匹配粘液球。遍历真实 3×3 网格验证配方并 assemble，支持有序和无序配方与数据组件产物。排除粘液球自身加工以及有容器返还的配方；多物品／多粘液球配方不自动转换。批量结果保留产出数量并按最大堆叠拆分。

提示与思索按流沙结构补齐中英文。使用现有流体纹理加绿色着色，桶使用 NeoForge 动态流体容器模型，没有新增自绘贴图。

GameTest 验证 12 个活塞加工成 12 个黏性活塞，输入查询不修改物品，鼓风机与雾化器均识别。尚未客户端视觉复验；JAR 未更新。
