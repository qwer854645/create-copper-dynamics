# 铜包裹观察窗与液体显示

用户新贴图为铜包裹加入透明窗口，原模型只有外壳单面且动态内容包装器已停用。现四种铜包裹尺寸均增加反向内壁与 tintindex=0 的内部液体体积，声明 cutout_mipped，并重新安装 FluidCanisterModel。

动态缓存身份加入实际物品 ID，避免四种尺寸共用一个外壳；液位按各模型液体范围计算，使用实际流体 still sprite 与颜色，液面随液位下降。空包不显示液体。运输 partial 和 rigging 也按实际尺寸建立缓存。内壁遮住从窗口向内看时的背面透明穿透。

保留用户外壳贴图。编译及独立客户端资源加载通过；持有、掉落实体、锁链和蛙港的实际显示仍需复验。PNG 未改动。
