# 移液臂直连烈焰人燃烧室

烈焰人燃烧室及其方块实体子类是移液臂的特例目标，不受 `fluidArm.allowDirectContainerInteraction` 限制，无需舱口。距离、端点选择与移液臂动力规则仍然生效。

注入优先使用燃烧室现有的侧面流体能力；第三方处理器拒绝时，回退到 CCD 的桶燃料适配。普通熔岩桶、CCD 超热介质桶，以及被原生／附属 `tryUpdateFuel` 识别的其他流体桶均可使用。每累计 1000 mB 插入一次对应桶燃料，部分流体保存在燃烧室 NBT，不混合不同流体。继承燃烧室的供热等级、燃烧时间和继续加料限制，不把任意流体强制认作燃料。

第三方仅支持专有化学品、未暴露流体能力且其桶也不被燃烧室认可时，需要额外适配，不保证仅凭“来自其他模组”即可燃烧。水等非燃料拒绝注入。移液臂燃烧室端点只输出供料，不抽取燃料。

93 项基础 GameTest 通过，包括默认配置下直连目标、普通熔岩分批注入、模拟无副作用、拒绝水，以及原有超热介质燃烧测试。尚未完成每个第三方燃烧室接口和机械臂动画实机联调。
