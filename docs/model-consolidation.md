# 模型整理

本轮移除两种泵的 96 份逐方向模型与三通 48 份逐方向仪表模型，改用 blockstate 原生 X/Y 旋转。

必须保留的少量基准模型：原生 blockstate 只有先 X 后 Y 旋转，不能用单一不对称基准覆盖 24 个空间朝向，因此在需要时保留 cross 基准；泵的反向箭头保留反向状态模型。它们引用相同贴图，不重新绘制。

物品若与方块主体几何完全相同，改为 parent 继承，本轮找到并合并一处。含静态轴、指针的物品展示模型暂保留，因为方块动态部件不自动在物品中显示。

动态轴、指针、舱门、托盘、包裹尺寸与开关模型尚未进一步合并。这些是先报告的例外，继续处理前需要确定是否接受改用自定义物品渲染或动态组合的复杂度。

两种泵共 96 状态的新旧模型坐标、面方向、纹理变量与 UV 旋转逐项比对通过。未构建或启动客户端，实际渲染仍需复验。既有用户贴图和其他工作区修改未覆盖。
