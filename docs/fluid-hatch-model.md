# 流体舱口模型

普通流体舱口保留 Create 6.0.10-280 物品舱口的三个原生几何构件、安装轮廓和物品显示变换，将框架换成铜色，并在原生斜面中央加入一个朝外的流体管口。管口直接使用原生 `fluid_pipe/rim_connector/south` 与 `fluid_pipe/rim/south` 的几何及 UV，整体绕 X 轴旋转 -45°，端面中心位于模型坐标 [8,11.4,5.9]。内嵌斜面不处于方块边界，因此移除管口面的邻块裁切标记，避免邻块遮蔽内部接口。

`frame.png` 是原生 32×32 `hatch.png` 的铜色变体，使用 pixel-art 技能按整数像素改色；保留原生深色凹槽、下方小金属构件及全部 alpha。框架的磨损和像素布局沿用原生资源，没有增加铆钉。斜面铜板复用 CCD 已有的 16×16 `faucet/body` 贴图。

管口侧壁与开启端面直接引用原生 `pipes.png`。关闭端面使用其 32×32 派生贴图 `pipe_cap.png`，仅将孔内 32 个深色像素替换为灰色内盖，铜圈和全部透明度保持不变。开启后端面回到原生深色管孔。原生舱口本身也是切换贴图表达开合，没有新增舱门动画或方块实体渲染器。

开合仍表示手动容器交互后的短暂反馈，10 tick 后复位；关闭外观不阻断流体代理。四向状态、含水、碰撞、安装、扳手、手持容器操作及后方容器访问逻辑均不修改。物品模型继续继承关闭模型。

智能流体舱口暂不进行本次外观改造：其关闭模型直接继承原生物品舱口并覆盖黄铜机壳，等价于修改前的完整继承结果，避免普通版新管口穿入原生过滤槽。开启和物品模型继续按原有方式继承，过滤坐标及渲染不动。

生成器为 `tools/create-fluid-hatch.cjs`，参数为解压后的 Create 源码根目录。`outputs/fluid-hatch/preview.png` 展示原生舱口、关闭、交互开启和侧面，`textures.png` 展示两张派生图集，`model.meta.json` 记录资源来源与变换。仅静态检查与离线渲染，未构建、测试或启动游戏；离线预览不是游戏内验证。
