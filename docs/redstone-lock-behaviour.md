# 红石锁定行为

红石流体阀改为无信号开启、有信号关闭。默认状态、带信号放置状态与运行时原生指针目标均已反转；保留原生 FluidValveBlockEntity 控制 ENABLED 和管网通知。灯面贴图按信号语义调整为关闭状态亮灯、开启状态灭灯。中英文说明同步。

检查现有代码：流体传输器、流体桥/扩展端口、普通与智能龙头、智能集液栅、铜供水器、雾化器均在有信号时暂停对应工作。雾化器只停止雾化、保留气流；智能集液栅暂停自动收集与排放，手动容器交互仍沿用现有逻辑。普通集液栅不提供红石控制。

保留用途例外：三通收到信号切换支路；红石双向动力泵收到信号切换流向；流体打包机沿用 Create 红石触发打包，流体理包机继承原生理包机行为。储罐、舱口、机械臂等没有新增红石锁定功能。

新增服务端 GameTest 验证无信号开启、加信号关闭、撤信号重开，通过。完整 53 项中 52 项通过，既有智能集液栅轮廓简化检查失败。客户端光影模组在服务端测试后已恢复。未更新发布 JAR。
