# 流体传输器模型

沿用用户认可的增压泵美术：简洁铜壳、原生接口、不规则像素材质，不增加铆钉、动力轴或外置轴承座。

铜壳基础贴图为 16×16，左右及上下过滤面图集为 32×32。铜面与面板先按 16 像素布局，再用最近邻放大两倍；只有箭头使用更细的整数像素网格，便于在面板旁的窄条中画出完整箭头，不引入插值或抗锯齿。铜面手工安排连续、非对称的铜色像素簇，避免重复排列的小点。四面过滤面板取消自画灰色方框，直接使用 Create 智能流体管道过滤组件的黄铜面板：来自 `smart_pipe_2.png` 的 [8,8,16,16] 区域，对应原模型过滤边框 north 面的 UV。完整保留原生像素布局与透明度，适配为四面平装面板，中心仍用于原生过滤图标。此处复用的是面板外观，不移植智能管道的倾斜安装结构。

参考动力泵“箭头表示流向”的语义，侧面常驻小型深铜色完整箭头，包含连续箭杆和箭头，替换原先三像素的小折线标记。按用户最终要求，箭头在 32 像素图集内为 7×5 像素，对应 3.5×2.5 模型单位，颜色为 RGB(123,61,41)。箭头位于过滤面板外侧，不遮挡图标；沿左右面 UV 的 +U、上下面 UV 的 +V 指向本地 +Z 输出端。原有六向方块朝向变换同步旋转箭头。用户于 2026-11-18 明确选择机身常驻箭头，不新增持扳手时的悬浮提示。这是适配传输器贴图空间重新绘制的箭头，不声称复制了动力泵的箭头资源。

中央壳体为 [0,0,3]–[16,16,13]，保持前后直通。过滤面直接位于方块四侧表面，中心为 [16,8,8]、[0,8,8]、[8,16,8]、[8,0,8]，对齐现有 `FilteringBehaviour` 的交互中心；不再使用浮在机壳外的薄铁块模型。方块碰撞沿用现有整块形状。

前后管口直接导入 Create 6.0.10-280 的 `fluid_pipe/rim_connector/north`、`rim/north`、`rim_connector/south`、`rim/south` 原生几何，完整保留尺寸、UV、旋转和裁切设置，直接引用 `create:block/pipes` 贴图。原模型、管道贴图与所述黄铜面板像素归 The Create Team / The Creators of Create 所有，不标注为 CCD 原创；许可见 [Create LICENSE.md](https://github.com/Creators-of-Create/Create/blob/mc1.21.1/dev/LICENSE.md)。

本次只修改模型与贴图；前后定向转移、四面过滤、红石暂停、同向链式转移和无内部储液的实现不变，不添加 UI 或逻辑代码。继续使用现有原生 `SmartBlockEntityRenderer` 显示过滤图标。

`tools/create-fluid-transmitter.cjs` 接收解压的 Create 源码根目录，生成资源及 `outputs/fluid-transmitter/preview.png`，展示输入侧、输出侧和竖直摆放。`textures.png` 顺序为铜壳、左右侧、上下侧。仅静态检查与离线渲染，未构建或启动游戏。
