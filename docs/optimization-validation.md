## CPU 测量与限制

固定输入为活塞，配方管理器 1583 个工作台配方，预热 100 次、计时 1000 次 canProcess。旧全扫描样本为 227.6873 ms；索引实现 KJS 环境样本为 10.5973 ms（另两次为 10.7398、12.7414 ms）。基础环境索引样本 22.5785 ms。该跨进程样本受 JIT／硬件调度影响，不能当作稳定倍率或整厂 TPS 提升。

另提供 -PccdBenchmark 设备空闲 tick 微基准，每种 100 次预热、1000 次直接调用：万向泵 0.4131 ms、水龙头 0.1349 ms、打包机 0.3519 ms、储罐燃烧室 0.3125 ms。它们是在同一世界时刻直接调用空闲状态，不包含真实活动管网、网络传输、区块调度，不等同于1000个设备运行一刻。

原先建议的完整活动产线 TPS／同步包量前后对照尚未完成，需要独立固定存档、相同模组组合及网络观测。当前只完成可重复的 CPU 查询和空闲设备采样，没有伪造包量收益数字。
