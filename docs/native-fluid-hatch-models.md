# 流体舱口复用原生物品舱口模型

按用户要求，普通与智能流体舱口的闭合模型均直接继承 `create:block/item_hatch/block_closed`。模型几何、UV、显示变换和贴图均由 Create 提供，不复制模型内容、不生成或重绘贴图，原有 CCD 贴图保留。

当前两种舱口外观相同；智能版仍保留流体过滤功能。沿用现有固定舱口行为，不增加开合动画。形状使用 Create 原生 ItemHatchBlock 的形状，与继承模型对应。

智能版过滤槽直接使用 Create 原生 `HatchFilterSlot`，与物品舱口保持相同位置、45° 倾斜、缩放、朝向旋转和点击判定；过滤内容仍使用 CCD 的流体过滤行为。

Create 模型及贴图权利归原作者。本次通过资源引用使用，不标注为 CCD 原创。旧资源生成脚本会生成历史自制造型，如需重新采用原生模型，运行 `tools/use-native-hatch-models.py`，该脚本只写两个模型引用，不改写贴图。
