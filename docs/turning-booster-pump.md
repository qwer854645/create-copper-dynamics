# 转向增压泵

新增 `ccd:turning_booster_pump`。两个流体接口呈直角；管口对面的两个面保留原生半轴和现有增压泵轴孔，其余两个面为封闭铜壳。模型和预览只引用现有贴图，不改写用户美术资源。

继承 BoosterPumpBlockEntity，因此压力、距离与应力继续使用增压泵配置。保留原生流体运输行为和压力图遍历，仅适配背面方向分发、压力刷新及其他泵对转角接口的端点识别。PumpBlock.isOpenAt 对该方块使用实际两个端口；原泵不受影响。

FACING 与 ROLL 表示 24 种有序直角接口方向。REVERSED 只交换抽排角色，保持物理接口位置。扳手点击管口反转流向，点击其他面绕主接口调整弯口；水平旋转、镜像和结构变换同时转换两个接口。方向标记在反向时翻转。轴接口在内部按 1:1 转角传动，共用增压泵的动力传播适配与半轴渲染器。

无序合成可在增压泵与转向增压泵之间互换。包含创造栏、掉落、镐挖掘、扳手回收与中英文名称。

美术来源：现有 CCD 增压泵机壳及轴孔贴图、Create 流体管口模型与 pipes 贴图、原生机械泵方向标记、shaft_half 模型。沿用项目对对应上游资源的许可说明。

后续修正：扳手改为绕点击面所在轴整体旋转两个接口，不再点击管口反转、其他面单独循环 ROLL。模型生成器已按 Minecraft Direction.getClockWise 的实际方向修正三个轴的变换，避免部分 ROLL 下轴孔和运行时半轴错位穿模。48 个模型状态的管口与轴孔方向静态校验通过。

按项目默认要求，本轮只生成实际资源离线预览并做资源静态校验，未构建、运行 GameTest 或启动客户端。实际旋转操作与动力网络仍需运行验证。
