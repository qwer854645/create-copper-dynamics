# 护目镜逐元件对照（Create 6.0.10-280）

本次读取实际发行 JAR 的方法与继承关系；没有给 Create 原生类打显示补丁。

- 增压泵、转向泵、垂直转向泵、红石泵、双向泵：继承 PumpBlockEntity → KineticBlockEntity，原生泵没有额外通用状态面板，保留原生应力信息。
- 调频泵：原生应力信息不变。目标流量、红石强度、单侧距离为 CCD 独有数据，使用动力统计的灰色标签与缩进一级的青色数值；信号上限深灰。便携泵继承相同结构但不显示红石强度。
- 缓存泵：原生动力统计＋原生单罐储液格式。
- 移液臂：ArmBlockEntity 未覆盖护目镜动力统计，继承 KineticBlockEntity。保留其应力信息及原生缺目标提示风格，仅替换物品臂名称。携带液体按储液行格式显示灰色流体名、金色数量；状态不再重复“状态：”前缀。
- 智能储罐、横向储罐：参照 FluidTankBlockEntity 使用的 IHaveGoggleInformation.containedFluidTooltip。零/一种流体直接调用该原生接口；多流体共享容量只能扩展为多条流体名/数量及一次总容量，不能冒充多个独立储罐。潜行显示流体种类上限，数据不能删除。
- 流体舱口、智能舱口：没有自身储液，显示实际目标的储液。普通目标调用原生接口，共享储罐走上述扩展；断开连接使用简短黄色状态。
- 铜集液栅：参照 SpoutBlockEntity 原生储液接口。无限液源提示是 CCD 的采集信息。智能集液栅追加红石暂停/就绪信息。
- 雾化器：EncasedFanBlockEntity 继承原生动力统计；储液参照 SpoutBlockEntity 原生接口，新增段前仅一个空行；雾化状态为 CCD 独有。
- 铜水槽、潮涌箱：CreativeFluidTankBlockEntity 原生不输出护目镜储量；CCD 显示真实的无限供水与自动供水状态，不伪造有限容量。保持用户确认的“无限供水”。
- 创造输送储罐：原生创造罐没有可复用的无限量提示；选定流体灰色、无限供应金色、模式灰色，按原生流体/标签格式扩展。
- 流量计：参照 SpeedGaugeBlockEntity 的读数结构，标题不再与正文重复“流量”；读数与单位一起青色。不会显示无意义的应力消耗。
- 红石阀、三通阀：原生 FluidValveBlockEntity 没有专用护目镜状态方法。CCD 独有的开关/通路状态使用标题和简短状态行，不伪称存在原生阀门状态模板。
- 流体传输器、龙头、智能龙头：不存在完全同构原生元件，保持简短名词标题与状态行，不添加计费/配方实现描述。
- 万向泵：保留原生动力统计；按方向列出 CCD 端口模式，全关闭显示未设置接口，不留空段。
- 流体打包机：原生 PackagerBlockEntity 没有专用护目镜方法。保留 CCD 的过滤、等待及剩余货物诊断，使用原生缩进/数量格式。
- 流体理包机：继承原生 RepackagerBlockEntity，不添加假的状态面板。
- 流体工厂仪表：FactoryPanelBlockEntity/Behaviour 的继承提示不另造统一模板；mB 数量适配保留。
- 储罐燃烧室：BlazeBurnerBlockEntity 没有同构储液提示，储罐直接使用原生单罐接口；供热状态与剩余时间是 CCD 独有诊断。
- 扩展端口/桥接：不拥有容量，显示可访问流体名和金色数量；不累加共享虚拟槽容量。

结论：可复用的原生组件直接复用；CCD 独有信息采用同一排版语言，但不能承诺其文字与不存在的原生功能“完全一样”。本轮不改变输液、加工或红石逻辑。编译/静态核对不代替客户端中英文实际显示验证。
