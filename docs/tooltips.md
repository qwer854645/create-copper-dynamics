# 提示与物品说明

最新约定：严格复用 Create 已有术语，不为同类信息自行命名。智能储罐、扩展端口与桥接器的流体清单直接使用 `create.gui.goggles.fluid_container`（流体容器信息：）；共享容量使用 `create.gui.goggles.fluid_container.capacity`。流体名称与数量分行、颜色与缩进沿用原版形式。仪表目标数量与长按提示复用原生语言键／原文。

物品说明只保留用途、必要工作条件与操作。已删除空款样品、实现细节、兼容加载状态等额外解释，七种加工介质仅描述对应加工用途。中英文同步。最新校验为各 382 个语言键、34 组说明；格式参数、高亮及编号校验与 build 通过，未启动客户端。

## Create 风格

对照实际依赖 Create 6.0.10 的 ItemDescription 和原版物品说明，保留原生 Shift 用途／工作条件、Ctrl 操作说明、自动换行及 STANDARD_CREATE 高亮。短句描述玩家能做什么、需要什么和操作结果；不向玩家展示接口、缓存、注册表和内部调度。

`tools/rewrite-tooltips.py` 维护中英双语文本。每个物品采用 summary、成对连续编号的 condition/behaviour 与 control/action；只在这些字段使用成对下划线强调。物品名称、注册 ID、控制逻辑、配置路径与默认数值不变。

## 本轮覆盖

- 重写所有公开设备及物品用途与操作，包括横向智能储罐、端口与桥接器、两类包裹、流沙和七种兼容介质。不同包裹尺寸共用各材质的说明，不重复维护尺寸变体。
- 更新旧名称与过时操作：包裹不再称罐／盒；雾化器手持操作覆盖任意面，管道仅侧面；端口不能延伸端口；传输器按箭头描述流向；空包裹说明为外观样品。
- 重写护目镜标题与状态、操作反馈、地址复制／粘贴提示、仪表输入提示和配置说明。短状态不包含教程，长操作说明放在物品说明里。
- 桥接器护目镜信息使用 CCDTooltip 的原生分组与缩进；铜包裹地址改用可翻译标签。
- 配置说明明确单位、倍率、特殊值以及重新进入世界生效；高风险操作明确说明清除流体、容量损失或拆包溢出掉落。
- 兼容介质注明加工提供者，不把注册了流体等同于已经安装对应加工功能。原版细雪桶仅补充 CCD 的用途说明。

## 校验

`tools/check-tooltips.py` 检查语言键一致性、格式参数位置／类型、成对高亮、说明连续编号及静态翻译引用。语言 JSON 为 UTF-8；PowerShell 默认代码页显示乱码不表示文件损坏，以 JSON 解码检查为准。

原生 UI 的按键提示、应力面板和翻译属于 Create，继续复用。此次未启动客户端，说明换行、实际按键及屏幕布局仍需客户端复验。
