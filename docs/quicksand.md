# 流沙与批量喷砂

- 流体 ID：`ccd:quicksand`、`ccd:flowing_quicksand`，桶为 `ccd:quicksand_bucket`。可通过管道、铜桶、储罐和流体物流处理，并可以在世界中放置。
- 动力搅拌：1 个沙子 → 1000 mB 流沙，不要求加热。
- 普通鼓风机：在气流路径中放置流沙，后方掉落物或传送带物品按 Create 原生批量加工机制喷砂。
- 雾化器：装入流沙即可喷砂，耗液沿用普通雾化媒介配置。规则数据包仍可覆盖默认行为。
- 喷砂直接查找当前 `create:sandpaper_polishing` 配方并按整组物品应用，无需额外注册重复的喷砂配方。数据包和脚本新增的标准砂纸打磨配方也能被识别；非物品配方或特殊代码式砂纸行为不在此范围。
- 安装 Connected 时，优先发现注册表中现有 `sanding`／`sandblasting` 加工类型并复用；若 Connected 没有提供该类型，则继续使用 CCD 的砂纸配方适配器。Connected 主分支本身的喷砂触媒依赖其他附属的加工类型，不能假设只安装 Connected 就有独立喷砂配方类型。无论有无 Connected，CCD 均不克隆砂纸加工配方。
- 流沙纹理为简易沙色像素动画，后续可进一步调整外观。没有增加生物伤害、窒息或沉陷机制。

普通鼓风机只识别实际流沙方块，注册的 CCD 加工类型将命中转交现有喷砂类型（如有）；不改变其他触媒的类型选择。

验证：build 与全部 26 项 GameTest 通过；新增用例验证 16 个玫瑰石英整组打磨、世界流沙触媒查询和雾化器默认规则。不包含 Connected 合装环境验证或客户端流体视觉验证。
