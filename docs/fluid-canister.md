# 流体罐

原“流体包裹”的显示名称改为“流体罐 / Fluid Canister”。物品名、提示及相关说明统一使用新名称。注册 ID 仍为 `ccd:fluid_package`，继续继承 Create 的 `PackageItem`，复用地址、运输、物流识别与卸液机制。

模型采用四个整数网格长方体：铜色罐身、底沿、上盖和密封盖。模型边界保持为 X/Z 2–14、Y 0–12，沿用原来的 12×12 包裹尺寸和原生吊索。容量仍为 4000 mB，通过流体打包机卸液。

贴图为原创的 16×16 像素图。使用 pixel-art 技能逐像素绘制，参考本地 Create 6.0.10-280 的铜机壳与流体储罐贴图，采用其中的铜色和中性框架色板，重新设计像素布局。总计八种颜色，采用清晰色块、单像素边缘和液滴标签；不使用渐变、抗锯齿、斜切几何或细碎装饰。UV 保持一个模型单位对应一个纹理像素。

所有贴图完全不透明，不依赖流体染色，适配 Create 原生包裹实体的 `RenderType.solid()` 缓存渲染。物品与物流实体使用同一个模型；移液臂的独立载液袋不在本次修改范围内。

`tools/create-fluid-canister.cjs` 使用 Node.js 与 sharp 生成模型、像素贴图及离线预览，参数为解压的 Create 源码根目录。`outputs/fluid-canister/preview.png` 展示三个视角；`textures-source.png` 为原尺寸贴图拼图，`textures.png` 为最近邻放大的像素对照，顺序见 `model.meta.json`。

本次仅进行静态资源检查与离线模型渲染，未构建或启动游戏。离线预览不包含游戏内环境光遮蔽和光影效果。
