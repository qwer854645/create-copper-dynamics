# 垂直转向增压泵

新增 `ccd:vertical_turning_booster_pump`，显示名“垂直转向增压泵”。相对于转向增压泵，仅将原来的同平面双轴接口改为垂直于两个流体管口所在平面的贯通轴。轴两端使用直通传动的同一旋转系数。

继承转向增压泵，复用方块实体、流体口／压力逻辑、配置、应力、放置、扳手和半轴渲染。模型沿用用户认可的转向泵，仅变更轴孔材质位置与物品半轴方向；保留两个管口。提供两种转向泵的无序互换配方。

生成器：`tools/create-vertical-turning-pump.cjs`。预览：`outputs/vertical-turning-pump/preview.png`。

验证：Java 编译、贴图引用和全部 48 个方向／反向状态的模型轴口对应关系检查通过。新增 GameTest 覆盖 24 个管口朝向的轴口和转速系数，现有放置测试加入新物品；GameTest 尚未执行，尚未客户端复验，JAR 未更新。
