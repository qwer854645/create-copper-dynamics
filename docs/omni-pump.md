# 万向泵

`ccd:omni_pump` 六个面默认关闭，显示空白铜壳。扳手右键只循环被点击面：关闭 → 输入 → 输出 → 应力口 → 关闭；潜行扳手沿用 Create 拆卸。

输入／输出复用三通管口美术，应力口使用既有轴孔贴图与原生动态半轴。一个主体、三个端口模型，通过 multipart 旋转覆盖六个方向。配方：增压泵 + 精密构件。

多个应力口按 1:1 传动。输入和输出角色不随转速正负改变。最大输送速率为绝对转速的一半（最低 1 mB/t），所有输出与外部抽取共享每刻输出预算；多面优先顺序按时间轮换。范围和应力沿用增压泵配置。

采用 2000 mB 共用内部缓存和有界管道遍历；输入主动从容器抽液，输出主动向容器供液，遵循管道连接与流体筛选，遇其他泵停止遍历。关闭／应力面不暴露流体能力，输出面仅在有动力时允许抽取。支持流量计记录。当前不向开放世界端口排液。缓存随方块实体保存，拆卸未满缓存时不会保存到物品。

验证：Java 编译、资源引用检查通过；六面独立循环／能力与轴口切换、原生管道输送、停机停止以及流体守恒 GameTest 通过。64 项测试仅已有智能收集栅形状检查失败。尚未客户端视觉复验，JAR 未更新。
