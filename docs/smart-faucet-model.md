# 智能龙头模型

沿用已完成的铜龙头几何，使用 Create 黄铜块色板精确替换 CCD 铜面八级色阶，保留不规则像素簇；深灰手柄、原生背部流体管口和分液池喷嘴不变。新增黄铜贴图为 16×16，未添加铆钉、灯、储液窗或其他装饰。

用户于 2026-11-18 明确选择“正面一块，像智能流体管道，点击位置随面板对齐”。因此过滤不再从左右和顶部设置，只在当前 FACING 的正面配置。前方面板为 [4.9,4.9,9.8]–[11.1,11.1,11.2]，相对原定六单位面板的上下左右各扩 0.1 单位，避免与喷嘴箍环侧面、弯管顶面共面闪烁。正面中心 [8,8,11.2]；交互中心 [8,8,11.25] 位于表面外侧，图标比例缩为 .375，对应约六单位宽的面板，不与顶部手柄重叠。

面板正面、背面及四侧的 UV 直接复用 Create 智能流体管道原生过滤边框组件（`smart_fluid_pipe/block` 第三个元素），将其 north 面的 [8,8,16,16] UV 用于龙头正面；直接引用 `create:block/smart_pipe_2`，不复制原贴图文件。原生倾斜安装结构没有移植，改为前端平装，适配龙头尺寸。

智能版开关子模型继续继承基础龙头，保持结构复用。方块状态由原有 16 条规则等价改为 multipart，加上四个水平方向的面板，不影响 OPEN/POWERED 的状态选择。物品模型组合关闭状态与前面板。原生 `FilteringBehaviour.forFluids()` 和 `SmartBlockEntityRenderer` 继续负责过滤与图标；只调整了过滤配置面、交互中心及显示比例，流体筛选、注液配方、传送带加工、红石暂停和无内部储液规则不变。

`tools/create-smart-faucet.cjs` 接收解压的 Create 源码根目录，生成黄铜贴图、两个继承模型、面板模型、状态和物品资源，以及 `outputs/smart-faucet/preview.png`。仅静态检查及离线渲染，未构建或启动游戏；过滤图标的实际交互和运行时显示尚未实测。

碰撞、选中和交互形状复用基础龙头的当前手柄形状，再合并上述过滤槽包围盒，统一按 FACING 旋转。右击非过滤槽区域可切换开关，普通手持物品同样支持；过滤槽继续由原生 FilteringBehaviour 处理。
