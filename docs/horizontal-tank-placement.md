# 横向智能储罐批量放置

横向储罐原先注册普通 BlockItem，没有原版 FluidTankItem 的整层补齐行为。原版实现硬编码竖直方向，因此使用独立 HorizontalSmartTankItem，按现有横向控制器的 structureOffset 计算端面。

在 2×2 或 3×3 储罐的轴向端面放置时补齐下一层；潜行或快捷栏有对称魔杖时只放一块，物品不足或整层有障碍时不追加补齐。额外方块仍走原生 BlockItem.place，保留权限、碰撞检查和物品消耗。放置前记录原控制器，避免第一块加入后控制器尺寸改变；新块继承邻接储罐轴向。

三项新增 GameTest 通过，覆盖正向、负向补齐，侧向观察时继承轴向，潜行单放及物品消耗。完整 50 项测试中 49 项通过；既有 coarseshapesmatchselection 因智能集液栅优化后 9 块轮廓超限失败，未修改该项。测试期间临时禁用的客户端光影模组已恢复。尚未在客户端手动验证，未重新打包 JAR。
