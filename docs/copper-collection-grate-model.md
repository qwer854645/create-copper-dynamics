# 铜集液栅：半格集液斗试版

将原 4/16 高的平栅改成 8/16 高的集液斗。外形由上方 16×16 铜边框、14×14 上槽、12×12 下槽和底部原生管口组成，逐级收口。顶框位于 Y=7..8，四条深灰金属栅条位于 Y=6..7，下沉一像素；栅条长度 Z=3..13，端点与内壁相接，不与槽壁顶面重叠。槽内横向空间 X/Z=3..13，槽底 Y=3，中央保留 4×4 排液孔。

几何和材质表达先参考本地 Create 的工作盆、管道口与已认可的 CCD 增压泵。底部直接引用 `fluid_pipe/rim_connector/down` 和 `fluid_pipe/rim/down` 的原生元素、UV、透明孔洞与边界裁切，不缩放或另画接口。底部流体口与现有向下排液逻辑一致；侧面仍提供原有标准流体能力。没有增加新的动力或工作行为。

四张贴图均为 16×16：body 铜壳、rim 铜折边、inner 深灰内衬、grate 金属栅条。按用户要求，铜面直接沿用此前认可的 CCD 增压泵 body 原图布局与色阶，只还原其中央轴孔专用的 4×4 像素为原始铜板颜色；没有重新使用被否定的碎块拼色、点状高光或接缝图案。rim 在同一铜面基础上绘制干净的上下折边。短槽壁的侧面 UV 连续上移六个像素，采样铜板上部明暗，不缩放、不改变像素密度，避免把铜板底部大片阴影重复拼到各层槽壁。

灰色栅条直接取用 Create 原生 industrial_iron_block 像素，内衬使用同图降低至 .65 亮度，不再另画重复的灰色小方格。材质来源归 Create，非 CCD 原创。模型使用 cutout_mipped，真实栅孔由几何空隙形成。内衬只替换对应实体壁面的材质，不额外叠加共面的装饰片。

选取、碰撞及交互轮廓按 22 个模型元素的长方体范围合并，保留凹口和栅条空隙。液体仍调用 Create/Catnip 的原生流体盒绘制；X/Z 为 3.0625..12.9375，底面 Y=3.0625，满液面 Y=5.8125，低于栅条底面 Y=6，按原生库存平滑液位缩放。未新增流体贴图或库存。容量 2000 mB、区域抽液、环境收集、标准能力、排液、配方和掉落保持原实现。

智能版继承基础版槽体、灰色栅条与原生底部接口，通过 copper 材质键覆盖为 CCD 自绘黄铜，并增加前侧过滤面板及四向放置；详见 `docs/smart-collection-grate-model.md`。过滤与红石工作逻辑仍共用现有实现。

生成器为 `tools/create-copper-collection-grate.cjs`，参数是本地解包的 Create 源码资源根目录，并使用其中的原版 water_still 参考纹理绘制存水示意。`outputs/copper-collection-grate/preview.png` 展示空槽、存液和底部管口，预览读取实际模型 JSON；真实游戏液体仍随库存、流体种类与原生动画变化。离线水面只用于预览，临时模型在 finally 中清理，不写入最终资源。

本次仅静态检查和离线模型预览，未构建、运行测试或启动客户端。铜壳复用 CCD 自绘增压泵材质，铜折边为 CCD 调整；工业铁、内衬、原生接口模型与 pipes 贴图归 The Create Team / The Creators of Create 所有，不标注为 CCD 原创或 MIT 美术，原版预览水纹归 Mojang 所有。
