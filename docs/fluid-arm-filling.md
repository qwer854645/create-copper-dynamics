# 移液臂注液与过滤

基座南北两面为 Create 原生调度模式，东西两面为过滤槽，二者互不覆盖。倒装时跟随基座高度。

短按东西过滤槽设置样品，长按同槽选择模式：

- 搬运流体（默认）：过滤流体，继续向已选流体容器或燃烧室交付。
- 物品注液：过滤可能的产物，向选定置物台或传送带上的物品执行 Create 注液配方。空过滤允许所有产物。

手持移液臂可选择置物台/传送带，自动标为输出；这些物品端点不会作为取液输入。模式和过滤保存并同步，原生调度策略继续使用原有枚举与调度方法。

预判不扣液、不改变目标物品，不掷配方随机结果。交付时检查当前目标及配方，完成一件物品后仅扣除所需流体，剩余载荷留在爪中。目标消失或不匹配时保留载荷。单次可搬运量沿用 1000 mB。

验证：136 项基础 GameTest 通过；新增错误产物拒绝、水瓶匹配、模拟无副作用、实际消耗 250 mB 后余下 750 mB、模式保存重载、四面槽位隔离。未进行客户端槽位和整机动画验收。
