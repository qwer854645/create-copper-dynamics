# 复进流体泵

ccd:reciprocating_fluid_pump：水平直通管口与横向双轴，应力与原版动力泵相同；扳手沿用泵的反向操作。造型参考脚踏气筒，使用铜底座、深色皮带材质气囊、黄铜压板。只有主体、气囊、踏板三种部件，无逐朝向模型；物品补充静态部件和两段原生半轴。气囊与踏板独立以支持往复动画，已先报告此模型例外。

服务器配置 reciprocatingPump.minimumFlow / maximumFlow，单位 mB/t，默认 0 / 128。0～15 信号按线性比例取整到 mB/t；反填上下限时排序。没有动力或过载时实际停泵。目标流速不随转速改变，转速决定动画频率和应力消耗。指示器显示目标流速，不能当作实际流量测量。

复用原生 PumpBlockEntity 管网，以压力=目标流量×2 接入原生 pressure/2 的单路流速换算；同时适配泵口和管路压力，零目标时不分发压力。距离由同一红石强度控制，配置 minimumRange / maximumRange，默认 0 / 32 格，表示每一侧的管路搜索距离，配置上限 256 格。距离或流量为零时停泵。远端管路发现覆盖配置最大距离，压力分发仍使用当前信号对应的距离。分支、其他泵和端点能力可能影响实际速率，因此不是强制全网计量上限。

配方为动力泵、铜机壳、传送带、电子管。包含名称、创造栏、掉落与扳手回收。信号控制流量是该设备的用途例外，并非红石锁定。

按美术任务默认约定仅资源校验与离线预览，未构建、运行 GameTest 或启动客户端。真实流量、动画、应力网络尚待运行验证；发布 JAR 未更新。

流速档位更新：默认范围改为 0～1500 mB/t，因此红石强度每级对应 100 mB/t。自定义上下限及插值结果均四舍五入到 100 mB/t 的整数倍，距离仍按格取整。该规则作用于目标流速；容器剩余量、分支与端点能力会使实际单次搬运量不是 100 的倍数。
