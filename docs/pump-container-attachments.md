# 泵的原生容器连接片

各CCD泵和创造输送储罐的方块实体渲染器共用 PumpContainerAttachmentRenderer。实际管口邻接流体能力时，使用 AllPartialModels.PIPE_ATTACHMENTS 中按世界方向配置的 DRAIN 部件；不重复绘制已有管口边框与连接筒。万向泵仅输入／输出面有效，缓存与创造源仅出口有效，转向泵按两个真实管口判断。沿用原生规则排除软管滑轮。

只改变世界模型附件显示，不改变能力注册、压力、输送、物品模型或手持交互。附件由运行时相邻能力决定，示意预览只将原生north连接片与调频泵组合，不能替代所有设备实际相邻时的视觉验收。部分CCD管口伸出方块边界，原生连接片位置与现有模型是否相交还需要客户端观察。
