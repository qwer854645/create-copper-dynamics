# 雾化器目标产物过滤

雾化器增加 Create 原生 FilteringBehaviour 物品过滤槽。槽位在非吹风／传动轴方向的侧面中心；各朝向沿用原生侧面过滤交互和物品显示。放入目标物品或 Create 物品过滤器设置条件，留空允许所有产物。原生行为负责保存、网络同步和过滤器规则。

原生／附属通过 RecipeApplier 执行的配方，在随机产物掷骰之前检查声明的可能产物：至少一个概率大于零的产物匹配便允许整条配方执行；副产物完整保留。不匹配返回未处理，保留输入。这个过滤不改变流体选择、耗液周期或实体效果，不为同一流体自动切换其他处理类型／配方。

自定义雾化配方检查 ItemRule 的 results。脚本规则安装过滤器后必须声明可匹配的 results；不能为探测产物提前调用业务回调。实际调用脚本后还检查其返回列表，完全不匹配则不转换输入。脚本调用自身产生的外部副作用无法回滚。第三方不经过 RecipeApplier 的自定义处理尚不保证支持。

更换过滤器会刷新雾化上下文计时，避免传送带／掉落物继续使用旧过滤状态。流体容器点击过滤槽时优先保留原生过滤交互，其余部位仍可灌注和取液。

验证：基础 GameTest 包含原生配方拒绝／接受、拒绝时输入保留、过滤设置保存和空过滤放行。客户端槽位操作、附属自定义处理和 Rhino 业务脚本未完成实机联调。
