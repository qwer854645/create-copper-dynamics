# 双向动力泵

新增 `ccd:bidirectional_fluid_pump`，继承原生 PumpBlock 与 PumpBlockEntity。使用原版泵的压力、距离与应力；正转时向 FACING 排出，反转时交换两端抽排角色，零转速使用原生停泵逻辑。等速反转另外刷新压力，避免原生 onSpeedChanged 只比较转速绝对值而跳过刷新。重新加载后重建压力。

外观直接复用当前增压泵模型与已有贴图。局部 Y 轴为流体通道，保留局部 Z 轴的两个相对传动轴及轴孔；局部 X 轴的两个轴与轴孔移除。六向放置同步转换管口和轴接口。机壳方向标记表示正转基准方向，反转时实际流向相反。使用独立半轴渲染器，保持 Flywheel 启用时显示。

配方：动力泵 + 传动轴 + 铜机壳，无序合成。包括掉落、创造栏、挖掘与扳手回收标签、中英文名称和描述。

美术来源与增压泵相同：Create 原生管口、半轴、机械泵方向标记及项目现有机壳与轴孔资源。生成脚本不改写现有贴图。

更新：显示名称改为双向动力泵，保留资源 ID。FACING 与 ROLL 共同描述管路及轴方向，默认放置轴水平；扳手绕点击面的轴整体旋转，水平旋转、镜像及结构变换也同时转换轴与管口。运行时 REVERSED 同步箭头显示，只有有效转速且未过载时更新；停转或过载保留最后方向。箭头不再固定表示正转基准。

模型纹理引用、中英文文本及 48 个模型状态的管口/轴孔方向静态校验通过；离线预览位于 outputs/bidirectional-fluid-pump/preview.png。遵循项目默认约定，本轮未构建、运行 GameTest 或启动游戏，实际动力反转与管路输送尚待运行验证，JAR 未更新。
