# 增压泵模型第一版

使用 pixel-art 技能绘制三张原创 16×16 贴图：铜壳、铜色流体法兰和深灰铁质轴承座。参考 Create 原生机械泵、铜机壳及工业铁块的色阶与结构表达，重新绘制像素接缝、加强纹、磨损和螺栓，没有复制第三方附属实现。

保持中央 12×12×12 泵体及六个接口的中心位置。流体轴两端统一铜色，法兰宽 8；其余四面的轴承座收小到宽 6，中央宽 4 的开孔容纳原生半轴。接口环由四条实体构件构成，贴图完全不透明，不依赖透明像素形成孔洞。壳体中心为深色泵芯凹位，不是贯穿式透明管。

只更新静态模型与贴图。方块朝向、管路连接、四面动力接口、碰撞、泵送能力和应力配置保持现有逻辑。原生半轴仍由现有 `BoosterPumpRenderer` 按实际转速绘制，静态模型没有额外轴体。

`tools/create-booster-pump.cjs` 接收解压的 Create 源码根目录，生成资源及 `outputs/booster-pump/preview.png`。离线渲染额外组合 Create 原生半轴，展示水平正反面与竖直摆放；轴按静止角度示意，游戏内仍沿用已有旋转逻辑。`textures.png` 为最近邻放大的三张贴图。

本次只进行静态资源检查和离线模型渲染，没有构建或启动游戏。
